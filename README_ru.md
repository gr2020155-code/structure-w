# Структура W

Попытка вывести постоянную тонкой структуры α, её связь с постоянной тяготения G и устройство частиц из небольшого набора положений о пространстве. Используются только положения и экспериментальные данные, без готовых постулатов стандартной физики.

**Автор положений:** Hrachya Danielyan
**Расчёты и проверки:** выполнены с помощью Claude (Anthropic) по правилам автора.

## α и G: одна связь

В Структуре W тяготение и заряд передаёт один и тот же механизм обмена. Акты обмена неразличимы (А-31), поэтому у обеих сил одна общая постоянная связи c_g. Различаются только источники: у массы это замыкания петли частицы, у заряда — несгасившаяся доля q обменов петли заряда.

Пусть a — шаг пространства, N — число шагов за один обход частицы (m = h/(c·N·a)). Тогда:

- α = c_g · q²
- G·m²/(ħc) = c_g / N²  →  **G = c_g · c³a² / (4π²ħ)**: массы выпадают, G задаётся только шагом a
- отсюда **α / G = 4π² q² · ħ / (c³ a²)**, а в единицах W (a = c = ħ = 1) просто **α / G = 4π² q²**

Размер обмена равен горизонту частицы с N = 1 (А-80), откуда c_g = 1. Тогда:

- α = q², q = 1/11,706;
- шаг a = 2π·l_P = 1,016·10⁻³⁴ м: **длина Планка получается без ввода**;
- отношение электрической силы к гравитационной для двух электронов (q·N_e)² = 4,17·10⁴², где N_e = m_P/m_e = 2,389·10²².

Так G входит в расчёт α: G задаёт шаг a, от которого α бежит до расстояния Z.

**Ограничения.** Выразить G только через α нельзя: нужно ещё одно число, абсолютная шкала масс, а она пока калибровка (А-14). Формула горизонта 2Gm/c² взята из ОТО. Статус — кандидат (В-269, В-271, В-235, В-270, В-272).

**Меняется ли G с расстоянием, как α?** Нет (В-272). Среда гасит только толчки обмена, у которых есть сторона; у замыканий (массы) стороны нет, поэтому тяготение не экранируется. G постоянна, а α растёт на расстояниях меньше комптоновской длины электрона (4·10⁻¹³ м). Поэтому α/G = 4π²q² на больших расстояниях, а на малых отношение растёт вместе с α. Со стандартной физикой это согласуется: тяготение измерено не ближе ~5·10⁻⁵ м.

## Честный статус

- **Все совпадения получены, когда ответ был уже известен.** Поэтому они имеют статус **кандидат**, а не доказательства. Нового предсказания, подтверждённого опытом, пока нет.
- В расчёте α используются **измеренные** массы частиц (лептоны, m_t) и измеренное рождение e⁺e⁻ → адроны. Массы и слабая сила в структуре пока калибровка (положение А-14), а не вывод.
- Результат держится на непроверенных звеньях (см. [`docs/alpha_chain.md`](docs/alpha_chain.md)):
  1. W-бозон — не отдельный вид, а пара уже учтённых частей (В-358); как в W рождается пара W⁺W⁻, не выведено;
  2. W из двух частей (В-348) опирается на выбор автора А-97 (половина инерции — у глобальной восьмёрки), который снял Х-01 (спин);
  3. «остаток пары — это q₀» (В-295) — прочтение сделано, когда цель была известна;
  4. избыток рождения адронов: прочтение ε = g выбрано данными из трёх (В-355).
- Два проверяемых отличия от стандартной физики: выше ~160 ГэВ α растёт быстрее (В-294, В-358); пары μ⁺μ⁻ в e⁺e⁻ рождаются на 0,73 % чаще точечного счёта, а по КЭД — на 0,17 % (В-355, В-356). Сегодняшние данные недостаточно точны для обоих: для второго нужно 0,28 %, лучшее сейчас (CMD-3) — 0,63 %.
- Открытых противоречий с данными в матрице сейчас нет. Х-01 (спин: обход нёс бы ħ, измерено ħ/2) снято 26.11 выбором автора А-97: инерция делится поровну между двумя концами обмена отставания, поэтому обход несёт ħ/2. Х-07 (водород) снято по правилу данных, Х-10 (недостача в 1/α) — данными об адронах. Все записаны в `meta.resolved`. Открыта аномалия магнитного момента электрона 1,16·10⁻³.

## Как устроено

- [`system/matrix.json`](system/matrix.json) — матрица: положения автора (А-), данные (Д-), расчёты (Р-), утверждения (В-), снятые утверждения (С-), противоречия (Х-). У каждого утверждения есть статус: `вывод`, `расчёт`, `кандидат`, `данные`, `открыто` или `противоречие`. Ошибки исправляются у источника, прежний текст сохраняется в поле `was`.
- [`system/check_matrix.py`](system/check_matrix.py) проверяет матрицу. Главное правило: `вывод` и `расчёт` не могут опираться на `кандидат`.
- [`alpha/`](alpha) — расчёты. Правила счёта (`*_rules_*.md`) записываются **до** запуска программы, вывод программы хранится в `*_output.txt`.
- [`docs/article_ru.md`](docs/article_ru.md) — обзорная статья, [`docs/predictions_ru.md`](docs/predictions_ru.md) — что можно проверить.
- [`docs/alpha_chain.md`](docs/alpha_chain.md) — 76 записей матрицы, на которых держатся итог по α и связь α–G, в переводе на английский.

## Запуск

Нужен Python 3.10+ и пакеты `numpy`, `scipy`.

```
pip install -r requirements.txt
python system/check_matrix.py
python alpha/end_to_end.py                 # шаг, наклон, край, заряды; q0 быстро (2 облака)
python alpha/q0_more_clouds.py             # q0 по 32 новым облакам (Р-113)
python alpha/hadron_dispersion.py <файл>   # адронная часть из данных R(s) (Р-97)
python alpha/tail_gee.py <файл>            # хвост избытка и узкие резонансы (Р-115)
```

`<файл>` — сводка PDG по R(s) для e⁺e⁻ → адроны, `rpp2022-hadronicrpp_page1001.dat` (https://pdg.lbl.gov/2024/hadronic-xsections/). Итог в таблице (137,280) собирается из этих программ, как описано в [`docs/alpha_chain.md`](docs/alpha_chain.md).

В Windows при неверной кодировке добавьте `-X utf8`.
