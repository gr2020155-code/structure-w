## Зачем

По правилу данных (meta.data_rule) мерилом служат только измерения. В цепочке α (В-285 – В-307, Р-64, Р-77) было три опоры на теорию:
1. край гашения выбран по потенциалу Юлинга — это однопетлевой расчёт КЭД (Р-64, исправлено 26.11);
2. наклон 2/(3π) на вид частиц как мерило — число КЭД;
3. итог сравнивался с 1/α(M_Z) = 128,9 — модельное; 136,86 вдали получено прибавкой измеренного спада к этому числу, не независимо.

Поэтому у цепочки α сейчас нет проверки по данным. Здесь она делается.

## Что берётся из положений и прежних счётов (не меняется)

- шаг a = 2π·l_P (c_g = 1, В-271);
- κ = 2/(3π) (В-289, Р-77);
- 1/q₀² = 66,29 ± 0,14 (q₀ = 0,12282 ± 0,00013, 8 пуассоновских облаков, Р-76);
- N_c·Q² по трём осям (В-304): лептон 1, u-тип 4/3, d-тип 1/3, нейтрино 0;
- W-бозон в рост не входит (В-294);
- размер формы вида f: D_f = 2ħ/(m_f c) (как D_t в Р-77);
- массы частей кварков — прочтение Rb (Р-82, В-313; Ra там опровергнуто): u = d = m_p/3, s = M_Λ − 2m_p/3, c = M_Λc − 2m_p/3, b = M_Λb − 2m_p/3; t — прямо.

## Развилки (закрытый список, все ветви считаются)

**Край (форма веса деления, Р-64):**
- S1 — только симметричная восьмёрка x = 1/2, E = −1,9635;
- S2 — любое деление с весом 1, E = −2,2703;
- S3 — вес x(1−x) (В-286), E = −2,1037.

Профиль вида f (из того же правила): вклад в наклон 1/α по ln r — κ·N_c·Q²·Σ_x w(x)·exp(−r/λ_x), λ_x = (ħ/(m_f c))·√(x(1−x)).

**Чтение переданного импульса Q = √|t| в расстояние (только для Ц2):**
- M1 — точечное: α при Q равно α_W(r) на r = ħ/(Qc). Вклад вида относительно «вдали»: δ(1/α) = −κ·N_c·Q²·Σ_x w(x)·E₁(r/λ_x).
- M2 — через амплитуду (Фурье потенциала α(r)/r): δ(1/α) = −κ·N_c·Q²·Σ_x w(x)·½·ln(1 + Q²λ_x²/(ħc)²). При S3 это совпадает по форме с однопетлевой формулой КЭД — но массы, κ, отсутствие W-бозона и кварки-части — из W.

Итого: для Ц1 — 3 ветви (S1, S2, S3), для Ц2 — 6 ветвей.

## Критерии (решено заранее)

- Ц1: ветвь проходит, если |1/α_W(0) − 137,036| ≤ 2σ_W, σ_W = 0,14 (от q₀). Если не проходит ни одна — цепочка α по данным **опровергнута в нынешнем виде** (что-то из шагов неверно), записать отклонение и не подбирать.
- Ц2: ветвь проходит, если отклонение от 440 ≤ 2·78 = 156 (·10⁻⁵).
- Выбор ветви: только среди прошедших обе цели; если проходят несколько — данные не выбирают, записать все.
- Никаких новых множителей и подстроек после счёта. Если всё мимо — это результат.
