# Правила счёта: 1/α вдали с убывающим избытком R выше 40 ГэВ (26.11.2026)

Записано и отправлено на GitHub ДО счёта. Программа: `alpha_excess_tail.py`, запись — Р-100. Продолжение Р-97 (136,774 ± 0,181) и Р-99 (данные выбрали (б): ε = c/ln(E/E₀)).

## Счёт

В Р-97 выше 40 ГэВ вес частей взят из W (Σ N_c·Q²) без избытка. Теперь выше 40 ГэВ добавляется избыток по (б), без Z (Z — отдельная форма, в W не описана; её вклад в данных отделён подгонкой):

Δ(1/α) = κ·∫ Σ_акт N_c·Q²·ε(E) d ln E от 40 ГэВ до энергии шага E_шаг = ħc/a ≈ 1,94·10¹⁸ ГэВ;
ε(E) = c/ln(E/E₀): ∫ c/ln(E/E₀) d ln E = c·ln[ln(E₂/E₀)/ln(E₁/E₀)].

Σ N_c·Q²: 11/3 от 40 ГэВ; с порога t (2m_t = 345,1 ГэВ) — 15/3 = 5.

- **(б1)** E₀ = 312,8 МэВ, c = 0,2513 (Р-99).
- **(б2)** E₀ = 139,57 МэВ, c = 0,3342 (Р-99).

Ошибка c — из подгонки Р-99 (пересчитывается в программе по той же ковариации); общая σ = √(0,181² + σ_хвост²).

## Критерий (решено заранее)

|1/α − 137,036| ≤ 2σ — проходит.

## Честно: прикидка в уме до записи правил

(б1): хвост ≈ +0,55 → 1/α ≈ 137,32 (+1,6σ, пройдёт); (б2): ≈ +0,69 → 137,46 (около +2,3σ, не пройдёт). Обе формы 1/ln — подгонка амплитуды по данным; правила для c из положений нет.
