# Правила счёта: постоянен ли член B или связан со счётом тактов (28.11.2026)

Записано и отправлено на GitHub ДО счёта. Программа: `b_term.py`, запись — Р-156. Основание: В-425 п. 5 (открыто); автор: «0,7 просто не может быть не связан с количеством тактов»; на предложение проверить — «Да».

## Что проверяется

Закон темпа (А-105) с членом B, который может зависеть от счёта тактов T (от самозамыкания 3D, В-425 п. 1):

g² = g₀²[Ω_r u⁻⁴ + Ω_m u⁻³] + C·T⁻ⁿ, u = k/k₀ = 1/(1 + z), g = d ln k/dT.

Ветви (все считаются, выбирают данные):
- **n = 0** — B постоянен (как в Р-134). Опорная ветвь.
- **n = 1** — B убывает обратно числу тактов.
- **n = 2** — B ∝ 1/T², как отношение «разница/фон» в В-423.

Сегодня (u = 1, T = T₀): Ω_r + Ω_m + C·T₀⁻ⁿ/g₀² = 1; Ω_B = C·T₀⁻ⁿ/g₀² — доля члена сегодня.

## Как считается

- Единицы: g₀ = 1, T в 1/g₀. T(u) — решение dT/d ln u = 1/g от u = 10⁻⁸ до 1.
- Начало: в светлую эпоху u = a·T^(1/2). Для n = 0 и n = 1 член B там пренебрежимо мал: T = u²/(2√Ω_r). Для n = 2 член C/T² входит в светлую эпоху наравне со светом: 1/4 = Ω_r/a⁴ + C, отсюда T = u²·√((1/4 − C)/Ω_r). Решение со светлой эпохой есть только при C < 1/4.
- При заданной Ω_m число C подбирается так, чтобы g = 1 при u = 1 (brentq). Если корня нет, ветвь при этой Ω_m решения не имеет.
- Трактовка красного смещения та же, что в Р-132–Р-134 и Р-155: 1 + z = k₀/k (В-374); D2 — путь в сегодняшних шагах (В-324); линейка мерит темп: D_H/r_d = 1/g(z), D_M/r_d = ∫dz/g (В-387).
- Ω_r = 4,57·10⁻⁵ (h = 0,7354, Р-133).
- **Честно о начале.** При n ≥ 1 член C/Tⁿ бесконечен при T → 0. По А-100 бесконечность — противоречие, поэтому у самого начала такой закон должен меняться, как в В-371. На данных (z ≤ 2,33 и сверхновые) это не сказывается: вклад первых тактов в T на поздних z — доли процента.

## Данные (сырые и обработанные, как в Р-155)

- **Д-80:** DESI DR2, линейка звука, 13 чисел с ковариацией.
- **Д-66:** Pantheon+, 1590 сверхновых при z > 0,01, полная ковариация, светимость M свободна.

## Критерий (тот же, что в Р-134)

Для каждой ветви Ω_m и g₀ (в единицах 1/r_d) подбираются по линейке. Ветвь проходит, если выполнены оба условия:
- линейка: вероятность χ² ≥ 0,05 при 11 степенях свободы;
- сверхновые при той же Ω_m: Δχ² ≤ +11 относительно опорного 1403,3.

**Для сравнения (не засчитывается):** лучшая Ω_m по одним сверхновым; T₀·g₀; Ω_B сегодня; возраст при h = 0,7354; действующий показатель w сегодня, w = −1 + n/(3·T₀g₀).

## Честно: что я знаю до счёта

- n = 0 повторит Р-134: линейка 10,3 на 11, сверхновые +3,9.
- При n = 1 член B сегодня ведёт себя как «тёмная энергия» с w ≈ −1 + 1/(3·0,97) ≈ −0,66. Линейка DESI и Pantheon+ хотят w около −0,9 при постоянном w.
- **Ожидаю:** n = 1 — линейка, скорее всего, пройдёт (около 13–18 на 11), сверхновые — около +8…+20, скорее не пройдёт.
- n = 2: C = Ω_B·(T₀g₀)². Для доли около 0,7 при T₀g₀ около 1 нужно C ≈ 0,6 > 1/4, а решения со светлой эпохой при C > 1/4 нет. **Ожидаю:** при C < 1/4 доля Ω_B около 0,7 возможна только при T₀g₀ < 0,6; закон близок к степенному (такие отвергнуты, В-386), то есть не пройдёт. Возможно, решения нет вовсе.
- Если пройдёт только n = 0, то член B по данным постоянен. Тогда 0,7 — показание счёта тактов только через падение доли замкнутых связей (В-425 п. 2), а сам B — постоянная, которую ещё надо вывести.
