## Что из положений: математика

По кинематике В-374: 1 + z = k₀/k и dD = (1+z)·dT. Отсюда:

- dD/dz = (1+z)·dT/dz;
- d ln k/dT = −d ln(1+z)/dT = 1/(dD/dz) = 1/D_H.

**Значит, линейка BAO прямо измеряет g = d ln k/dT** — относительный темп роста плотности связей за такт, при плотности k/k₀ = 1/(1+z). Единица — 1/r_d.

**Раскрываю:** с точностью до обозначений это кинематика официальной космологии — у них масштабный фактор a = k/k₀ и время t = T, а g — то, что они зовут H. Поэтому функция, найденная по данным, будет их функцией a(t). Новое — только её толкование через структуру.

## Развилка в прочтении слов автора (замечена сейчас, после данных BAO — раскрываю)

Автор (В-376): «плотность быстрее растёт в "начале", затем медленнее… спад постепенный, но не линейный».

- **R1** (так прочитано в В-376): убывает скорость dk/dT, рост вогнутый. Линейка его отвергает (Х-12, Р-131).
- **R2:** убывает относительный темп g = d ln k/dT. Тогда рост может стать выпуклым позже, лишь бы g убывал. Проверяется здесь: функции ниже дают убывающий g.

## Функции g(u), u = k/k₀ = 1/(1+z)

| | Вид | Чисел |
|---|---|---|
| Г1 | g = a·u^(−1/p) — степенной закон k ∝ T^p (Р-131: не прошёл) | 2 |
| Г2 | g² = A·u^(−3) + B. В переменных структуры: u³ ∝ s — доля точек, различимых в 3D (k ∝ s^(1/3), В-375), так что g² = A·s₀/s + B | 2 |
| Г3 | g = A·u^(−3/2) + B — темп закона T^(2/3) плюс постоянная | 2 |
| Г4 | g² = A·u^(−2) + B — по площади (s^(2/3)) | 2 |
| Г5 | g² = A·u^(−n) + B, n свободно — какое n выберут данные | 3 |

## Проверки

1. **Линейка (Д-80).**
   - D_M = ∫₀^z dz'/g, D_H = 1/g, D_V = (z·D_M²·D_H)^(1/3), в единицах r_d. Отдельного r_d нет: масштаб уже в A, B.
   - Проходит при вероятности χ² ≥ 0,05 на 13 − (число чисел) степеней свободы.
2. **Сверхновые (Д-66, Р-90)** — без новых чисел: форма g взята из линейки, M свободен. d_L ∝ (1+z)·D_M. Порог Δχ² ≤ 11.
3. **Реликт (Д-79)** — без новых чисел:
   - θ = r_s/D(z*), где r_s = c_s·∫_{z*}^∞ dz/g, D(z*) = ∫₀^{z*} dz/g;
   - c_s ∈ [c/√6, c/√3], 1 + z* ∈ [1000, 1400], как прежде;
   - продолжение g за z = 2,33 — по той же функции;
   - диапазон должен содержать 0,010411.
4. **Для каждой прошедшей функции сообщаю:**
   - график g от k/k₀ (точки из D_H) и k/k₀ от T/T₀;
   - T₀·g₀ — возраст целого в единицах 1/g₀;
   - убывает ли g всюду (R2);
   - с какого такта рост плотности становится выпуклым.

**Итог по Х-12:** снимается, если функция, толкуемая через структуру, проходит проверки 1 и 2. Толкование — следующий шаг, по meta.fit_rule: функция найдена по данным, это раскрыто.
