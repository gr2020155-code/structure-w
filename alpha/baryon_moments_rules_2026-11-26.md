# Магнитные моменты других барионов: правила, записанные до счёта (26.11.2026)

Продолжение В-308 (моменты нуклонов) и В-312 (сложение спинов). Цель: тем же правилом без подгонки посчитать гипероны (моменты измерены — проверка) и очарованные барионы (моменты не измерены — предсказание). Список прочтений закрыт здесь; считаются все, итог сообщается по всем.

## Что берётся из матрицы

- В-14, Р-78: момент части w·Q·(m_p/M_part) μ_N; w — проекция спина части на целое в единицах ½.
- В-312 [кандидат]: |s|² = 3/4 (три оси поровну), у пары одинаковых частей поперечные составляющие независимы → веса пары по +2/3, третьей −1/3 (целое со спином ½); у N сонаправленных частей |J|² = N/2·(N/2+1) — у трёх (Ω⁻, Δ⁺⁺, спин 3/2) веса 1, 1, 1.
- В-305: заряды частей u = +2/3, d = −1/3 (петля «+» / «−»). Части s и c в W не выведены: s берётся как часть с зарядом −1/3 (петля «−»), c — +2/3 (петля «+»), отличаются только массой. Это допущение по составу из стандартной физики, а не вывод W.
- А-14: массы — данные. А-31: неразличимое не может иметь разный вес.

## Развилка R — масса обхода части (список закрыт)

- **Ra** (буквально В-308, R2): каждой из трёх частей — треть массы своего бариона, M/3. Для нуклонов совпадает с R2.
- **Rb** (собственная масса части, калибровка по массам, не по моментам): m_u = m_d = m_p/3 (из R2); m_s = M_Λ − 2·m_p/3; m_c = M_Λc⁺ − 2·m_p/3. Момент части не зависит от бариона. **Честно: Rb — это обычная модель составляющих кварков; совпадение по Rb не отличает W от стандартной физики.**
- **Rc** (доля массы бариона пропорционально собственной массе части): M_i = M·m_i/Σm_j, m_i из Rb. Для нуклонов совпадает с R2, для Λ и Λc⁺ — с Rb.

## Развилка L — какая пара сцеплена, когда все три части разные (Λ, Λc⁺, Ξc⁺, Ξc⁰)

Где есть две одинаковые части (одинаковый заряд и масса), пара — они (В-312, А-31), развилки нет: Σ⁺ = uu|s, Σ⁻ = dd|s, Ξ⁰ = ss|u, Ξ⁻ = ss|d, Σc⁺⁺ = uu|c, Σc⁰ = dd|c, Ωc⁰ = ss|c, Ξcc⁺⁺ = cc|u, Ξcc⁺ = cc|d, Ωcc⁺ = cc|s. Пара только по ориентации петли невозможна: у Σ⁻ и Ξ⁻ все три петли «−», а три сонаправленные части по В-312 дают спин 3/2, у этих частиц спин ½.

Для трёх разных частей:
- **L1**: две более лёгкие части образуют пару с нулевым спином (жёсткая противоположная пара, |S|² = 0) → веса 0, 0, 1. Это отдельное правило, в В-312 его нет (там поперечные части независимы).
- **L2**: две более лёгкие — пара как у одинаковых (сонаправлены, независимы): +2/3, +2/3, третья (тяжёлая) −1/3.
- **L3**: пара — две части одной ориентации петли (у Λ: d и s; у Λc⁺: u и c; у Ξc⁺: u и c; у Ξc⁰: d и s), веса +2/3, +2/3, третья −1/3.
- **L4**: В-312 буквально для противоположной пары более лёгких частей (поперечные независимы, s₁·s₂ = −1/4, |S|² = 1): по треугольнику пара 2/3, третья 1/3; пара делит свой вес поровну — по 1/3.

Сочетаний: R (3) × L (4) = 12. L влияет из гиперонов только на Λ.
