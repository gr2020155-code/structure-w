# Энтропия чёрной дыры через шаг a = 2π·l_P: правила, записанные до счёта (26.11.2026)

Открытый вопрос 13(б) работы «Чёрные дыры в Структуре W» (v1.4): все различимости дыры лежат на горловине, поэтому число состояний задаётся площадью; множитель не проверить, потому что «длина шага не определена». В structure-w шаг уже есть: a = 2π·l_P (В-252, при c_g = 1). Автор сказал «да, проверь» (26.11).

## Формула

S = (N точек горловины) × (s — энтропия на точку, в натуральных единицах). N = A/σ, где A — площадь горловины, σ — площадь одной точки.

## Варианты (список закрыт)

Площадь A:
- **A1** — горловина W: радиус по окружности e·GM/c² (В-138), A = 4π·e²·(GM/c²)².
- **A2** — горизонт ОТО 2GM/c²; берётся только для сравнения с формулой Бекенштейна — Хокинга при той же массе.

Площадь точки σ (размер точки — один шаг, А-06, А-89):
- **P1** — квадрат со стороной в шаг: σ = a².
- **P2** — круг диаметром в шаг: σ = π·a²/4.

Энтропия на точку s:
- **S1** — ln 2: две стороны обмена (А-03, А-85).
- **S2** — ln 2 / 2: сторону держит акт целиком, обе точки пары (А-88), поэтому одна сторона приходится на две точки.

## С чем сравнивается

Формула Бекенштейна — Хокинга S_BH = A_ОТО/(4·l_P²). **Это не данные, а теоретический результат.** Множитель 1/4 получен через температуру излучения Хокинга. По работе о чёрных дырах (раздел 6) устойчивого потока Хокинга в W нет, а энтропию чёрной дыры никто не измерял.

Поэтому результат — [расчёт] числа, а сравнение — только сообщение, не критерий прохождения. Сообщаются:
- отношение S_W/S_BH при той же массе (A1 против A2);
- энтропия на единицу площади в единицах l_P⁻² (сравнить с 1/4).

## Оговорка честности

До записи я заметил: при a = 2π·l_P формула A/(4·l_P²) — это ровно π² на каждую квадратную клетку a². Чтобы получить 1/4, точке нужно s = π² ≈ 9,87, то есть e^(π²) ≈ 2·10⁴ состояний. Из положений такое число не следует. Ожидаю, что варианты P·S дадут отношение порядка 0,06–0,17.
