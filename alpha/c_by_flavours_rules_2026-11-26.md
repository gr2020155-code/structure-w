# Правила счёта: растёт ли амплитуда притяжения частей с числом видов частей (26.11.2026)

Записано и отправлено на GitHub ДО счёта. Программа: `c_by_flavours.py`, запись — Р-101. Продолжение В-343.

## Что предсказывает В-343 без новых чисел

1/g = b·ln(E/E₀), ε = k·g, значит ε = c/ln(E/E₀), c = k/b. По В-343 п. 3 формы-дополнения добавляют (b₀ > 0), а сами части, как и всякие заряженные формы, гасят тем же механизмом (А-83, В-245) — каждый активный вид частей уменьшает b на одну и ту же величину β. Значит, b = b₀ − n·β, где n — число активных видов (3 — u, d, s; 4 — + c; 5 — + b), и **c растёт с n**. Величин b₀, β, k положения пока не дают — проверяется только направление.

## Счёт

Те же 9 областей и усреднение, что в Р-99 (Д-68). В каждой области c_i = (ε_i − Z_i)·ln(E_i/E₀), E₀ = 312,8 МэВ (В-343 п. 2), Z_i — часть Z из подгонки (б1) Р-99 (z₁V₁ + z₂V₂); ошибка c_i — из ошибки ε_i. Область D (58 ГэВ) не берётся: там почти всё — Z.

Средневзвешенное c по группам: n = 3 (A1, A2, A3), n = 4 (B1, B2), n = 5 (C1, C2, C3).

## Критерий (решено заранее)

- Наклон прямой c(n) по трём группам: рост подтверждён, если наклон > 0 больше чем на 2σ; опровергнут, если наклон < 0 больше чем на 2σ; иначе данные не решают.
