# Правила счёта: шкала свечей — проверка по сверхновым (27.11.2026)

Записано и отправлено на GitHub ДО счёта. Программа: `candle_scale.py`, запись — Р-137. Автор: «Шкала свечей».

## Что проверяется

В-393: на одних расстояниях свечи дают h = 0,735, а звук — 0,685. Если виновата шкала свечей, то сверхновые рядом (калибраторы, 7–80 Мпк, расстояния по цефеидам) и сверхновые в потоке (z = 0,023–0,15) светят по-разному. Нужный сдвиг: ΔM = 5·lg(0,735/0,685) ≈ 0,15 зв. вел.

Чтение в W: светимость может зависеть от окружения — плотности связей в галактике (А-106). Замена плотности по данным — масса галактики HOST_LOGMASS. У калибраторов медиана 10,33, в потоке 9,99. Это посмотрено до правил (раскрываю).

## Как считаю

- Pantheon+SH0ES: калибраторы (IS_CALIBRATOR, μ = CEPH_DIST) и поток (USED_IN_SH0ES_HF), ковариация STATSYS.
- Модель потока: D_L = (1+z)·(c/H₀)·∫dz/E, Ω_m = 0,297 (линейка).
- Два линейных числа — M и lg h, решаются точно (как в Р-133). σ — из матрицы Фишера.

## Проверки

- **С1 — масса галактики.** Граница 10 (lg M☉). Совпадающие классы: калибраторы лёгких + поток лёгких; тяжёлых + тяжёлых. Запись с массой −9 (нет данных) исключаю.
- **С2 — цвет сверхновой** c: граница 0, совпадающие классы.
- **С3 — растяжение** x1: граница 0, совпадающие классы.
- **С4 — обзоры:** поток только из тех обзоров (IDSURVEY), где есть калибраторы.
- **С5 — расстояние калибраторов:** ближние и дальние (граница μ = 32,33, медиана) — каждые со всем потоком. Если светимость зависит от расстояния, M уплывёт.
- **С6 — поток по z:** 0,023–0,04; 0,04–0,07; 0,07–0,15, со всеми калибраторами.

## Критерий (решён заранее)

Шкала свечей объясняет напряжение, если в какой-либо проверке выполнены оба условия:
1. для одного класса h согласуется с 0,685 (не дальше 2σ);
2. классы различаются между собой больше чем на 2σ (эффект реален).

Иначе по этим данным шкала свечей не объясняет. Сдвиг ΔM между классами сообщаю для всех проверок.

## Честно: что я знаю до счёта

- SH0ES (Riess и др.) делили выборку похожим образом, и H₀ держалась около 73 (по памяти).
- Ожидаю, что все подвыборки дадут h = 0,72–0,75, разброс до ~0,02, и ни одна не дойдёт до 0,685.
- Ограничение: эти данные проверяют только сверхновые. Цепочку «геометрия → цефеиды» они не проверяют: CEPH_DIST дан готовым. Независимая калибровка (красные гиганты TRGB, Freedman и др.) по литературе даёт ~70 — по памяти. Её данных у нас нет.
