### 1.2 Кодировка стыка
Хозяин H, добавленная часть X, элемент замыкания E. Записано для каждого случая:
- eH — восьмёрки хозяина через E (до стыка);
- lH — петли хозяина через E или касающиеся E (до);
- eP — восьмёрки через E после стыка (точка не восьмёрка);
- lP — петли через E после стыка (точка = одна петля);
- aX — петли добавленной части: восьмёрка 2, точка 1;
- aNet — петли, новые в продукте (восьмёрка с одной общей петлёй даёт 1);
- d — мерность замыкания в E после стыка;
- opp — пары восьмёрок противоположного направления в E после стыка.

### 1.4 Закон сочетания и константа
- **Закон A** [автор, «умножение по плоскостям»]: Δc = C · k^p(d), где p(1) = 2, p(2) = 4, p(3) = 4. Для 3D новая плоскость добавляет свою k⁴; отсюда «сумма по двум плоскостям»: τ − e = 1⁴ + 2⁴.
- **Закон B** — отвергнутая автором альтернатива: p(3) = 6, «произведение по трём плоскостям». Включён, чтобы честно считать попытки.
- **Константа**: (а) C подгоняется по одному мюону и предсказывает остальные 5 случаев; (б) C = 3/2 задано заранее и предсказывает все 6.
- Итого: 12 определений × 2 закона × 2 режима константы = **48 вариантов**.

### 1.5 Мера качества и нулевые модели
- Мера: число предсказанных случаев в пределах 1 % (основная), 3 % и 10 %; также наибольшая ошибка.
- Статистика — **лучшее по всем 48 вариантам**. Поэтому поправка на число попыток уже входит в P.
- Нулевые модели: каждое c независимо × exp(U(−ln2, ln2)) [«×/÷2»] или × (1 + U(−0,1; 0,1)) [«±10 %»]. По 20 000 повторов.

## 4. Что ново относительно Барута

- **Барут (1979)**: m_N = m_e(1 + (3/2α) Σ_{j≤N} j⁴); N — номер поколения лептона.
- **Здесь**:
  1. Индекс j прочитан геометрически: j = число восьмёрок хозяина, уже проходящих через точку замыкания O (D1). Числа те же, что у Барута. Это **толкование**, а не новое совпадение, и оно не проверяемо отдельно от формулы Барута.
  2. Закон «1D → квадрат» с тем же C = 3/2 даёт протон при k = 3 (+0,8 %). Но k = 3 получается только при другом счёте (петли через элемент), а не при счёте Барута. Поэтому одним правилом с лептонами протон не описан. Отдельно, как одно число, это совпадение уже оценено в прошлом отчёте: P = 0,02–0,08.
  3. Точки в O (π±, π⁰, D_s) по шкале относятся к классу 1 (~1/α). Но в закон с целым счётом они не входят, а их отношения (0,8645 и 5,65) ни одно определение не воспроизводит лучше 10–16 %.
- [вывод] **Новой статистически подтверждённой закономерности нет.**

## 5. Что это значит в рамках W (кандидаты)

1. [кандидат] Восьмёрка, добавленная в точку замыкания O, вносит (3/2α) · j⁴, где j — число восьмёрок, которые она там пересекает. j⁴ = j² · j²: «умножение по двум осям» новой плоскости. Это согласуется с правилом автора и с данными, но совпадает с Барутом. Задача W здесь — **вывести** 3/2 и j⁴ из обмена мест, а не подтвердить их.
2. [кандидат] Общая петля (протон) — стык другого типа. Её счёт — петли (3), а не восьмёрки (1). Если правило переходов 1D → 2D → 3D одно (позиция автора), то это противоречие. Его надо снять одним из двух способов:
   - (а) найти одно определение, которое даёт 1, 2, 3 для μ, τ, p (среди 12 естественных его нет);
   - (б) признать, что 9 у протона — не k² того же счёта, и тогда совпадение +0,8 % — случайность уровня P ≈ 0,02–0,08.
3. [кандидат] Точка в O не открывает новой плоскости. Её вклад — дробная доля C: 0,32 C (π±), 0,28 C (π⁰), 1,82 C (D_s). Если D_s — действительно «τ + точка», то отношение 1,82/0,32 = 5,65 близко к 81/16 = 5,06 (k = число восьмёрок в O: 3 против 2) только на уровне −10 %. Это не закономерность (P = 0,10).
4. [открыто] Чтобы класс 1 стал законом, теория должна сама дать вклад точки в O, а не только восьмёрки. Сейчас «класс 1» — это общая шкала 1/α, а не одно правило.

## 6. Слепое предсказание (записано до любого поиска частиц; частицы не искал)

Выдерживает проверку только барутовская часть: D1, закон A, C = 3/2. Поэтому единственное предсказание, которое следует из неё, такое:
- **«Третья восьмёрка противоположного направления в O мюонного креста»**: D1 направления не различает, поэтому Δ = (3/2α) · 2⁴ = 3289 m_e, **m ≈ 1786 МэВ** при C = 3/2 (1788 МэВ при C по мюону). Это то же, что τ.
- Оговорка [расчёт]: у пионов направление важно (π⁰ − μ = 57,4 m_e, π± − μ = 66,4 m_e). Определение с учётом направления (D11) даёт для той же формы Δ = 0, то есть m ≈ m_μ. Разброс по 12 определениям: от 106 до 1788 МэВ. Значит, предсказание **не определено** теорией, пока не задано, как направление входит в счёт.
- «Точка на общей петле протона»: разброс по определениям от 938 до 1359 МэВ. Все определения провалились на точках в O (ошибки ≥ 45 %), поэтому предсказания для точек **не даю**. Таблица — в выводе программы, § 6.

## 7. Ограничения

- Набор из 12 определений конечен. Отсутствие одного счёта доказано только внутри него. Определение, придуманное после просмотра чисел (например, «k = 3 для протона, потому что три петли», «k = 2 для τ, потому что две восьмёрки»), не может считаться проверкой.
- Кодировка (§ 1.2) содержит выборы для π⁰ и p. Альтернативы проверены, вывод не меняется.
- D_s как «τ + точка» — кандидат автора, а не установленная форма.
- В нулевых моделях каждая мишень меняется независимо. Модель ±10 % сохраняет то, что τ ≈ 16 C в пределах 10 %. Поэтому при допуске 10 % она даёт P ≈ 0,9: она проверяет только тонкую точность.
- C = 3/2 «задано заранее» только формально: значение известно из Намбу/Барута, то есть из тех же данных о мюоне. Поэтому попадание μ в режиме C = 3/2 — не независимое подтверждение.
