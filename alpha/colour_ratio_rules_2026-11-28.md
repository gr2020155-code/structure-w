# Правила счёта: отношение «перенос на перенос / перенос на часть» в W против C_A/C_F (28.11.2026)

Записано и отправлено на GitHub ДО счёта. Программа: `colour_ratio.py`, запись — Р-150. Автор: «Отлично. Считаем.»

## Что измеряется

В КХД C_F — сила, с которой кварк испускает глюон, C_A — с которой глюон испускает глюон. В теории Янга–Миллса для SU(3) C_A = 3, C_F = 4/3, отношение 9/4 = 2,25. Отношение не зависит от нормировки, поэтому его можно сравнивать со счётом W.

**Данные (Д-92):**
- ALEPH, четырёхструйные угловые распределения: C_A/C_F = 2,20 ± 0,09 (стат.) ± 0,13 (сист.) (G. Dissertori, hep-ex/9705016).
- Сводка LEP: C_A = 2,89 ± 0,21, C_F = 1,30 ± 0,09 (S. Bethke, hep-ex/0406058), отношение 2,22 ± 0,22 (мой расчёт без учёта корреляций).

**Оговорка (правило данных).** Величину достают из данных через коэффициенты, посчитанные в КХД (D_F, D_A, D_T). Поэтому сравнение — «мост, модельный»: проверяется, даёт ли W то же отношение там, где КХД его определяет.

## Что известно из положений

- **Часть** занимает k осей из трёх (В-304): d, s, b — k = 1; u, c, t — k = 2.
- **Перенос** — петля-дополнение, переносит ось i → j; ориентирована, поэтому i → j и j → i разные; вариантов 6; диагональных (i → i) нет — они ничего не меняют (А-28) (В-355 п. 1).
- **Мера** в канале осей — целая ось, доля 1 (В-355 п. 2).
- **Неразличимые конфигурации весят одинаково** (А-31): вес — число вариантов.
- **Перенос действует на объект**, если меняет его оси: забирает ось, которая у объекта есть, и ставит туда, где её нет.

**C_часть** — число вариантов переноса, действующих на часть. **C_перенос** — то же для самого переноса. Сравнивается C_перенос / C_часть.

## Счёт для части (развилки нет)

Часть с k = 1 на оси i: действуют i → j для двух j ≠ i — 2 варианта. Часть с k = 2 на осях {i, j}: действуют i → l и j → l (l — свободная ось) — 2 варианта. C_часть = 2 для обеих (у КХД C_F тоже одно для кварка и антикварка). Программа проверяет перебором.

## Развилка: на что действует перенос T = i → j

У переноса два конца: на j он ставит ось, на i — забирает. Положения не говорят, считать ли конфигурацию по концам (место действия) или по варианту переноса.

| Ветка | Что считается | Как |
| --- | --- | --- |
| B1 | по концам: каждый конец — отдельное место действия | конец j — как часть с осью j; конец i — как часть без оси i (k = 2 на двух других); варианты на каждом конце считаются отдельно |
| B2 | по вариантам, только те, что оставляют перенос переносом | вариант, дающий i → i (ничего), не считается |
| B3 | по вариантам, включая тот, что гасит перенос (j → i) | каждый вариант один раз |

Все три считаются перебором по 6 вариантам: результат «действие на T» — новая пара (откуда, куда) после составления.

## Критерий (решён заранее)

Ветка проходит, если C_перенос / C_часть попадает в 2σ данных ALEPH (2,20 ± 0,16) И сводки LEP (2,22 ± 0,22).

Для сравнения (не засчитывается): абелева модель (у переносов нет действия друг на друга) даёт 0 — данными исключена.
