## Что берётся из положений

- Механизм один (А-69, В-245) → у оси-канала та же единица, что у заряда: каждый вид формы меняет обратную связь на κ·w на e-кратное расстояние, κ = 2/(3π) (как в цепочке α), w = (число вариантов)·(доля)² (В-304 п. 3, «не лего»).
- 1/g = b·ln(E/E₀), b = κ·(A − P): A — формы-дополнения (добавляют, В-343 п. 3), P — сами части (гасят, Р-101). E₀ = 312,8 МэВ (В-343 п. 2).
- Избыток рождения ε = k·g, значит c = k/b = (3π/2)·k/(A − P).

## Ветви (все, без выбора заранее)

**Дополнения A:**
- (а) форма переносит одну ось от части к части, доля 1/3: (а1) упорядоченные пары разных осей — 6 вариантов, A = 2/3; (а2) неупорядоченные — 3, A = 1/3; (а3) все пары без полностью симметричной (она ничего не меняет, А-28) — 8, A = 8/9. От n не зависит.
- (б) среда добавляет недостающие оси, по каждому активному виду частей: (б1) одной формой-дополнением из 3 − k осей, 3 варианта, доля (3 − k)/3 (d-тип — 4/3, u-тип — 1/3); (б2) по одной оси отдельно, доля 1/3 (d-тип — 2/3, u-тип — 1/3).

**Гашение частями P (на вид частей):** (п1) как у заряда, 3·(k/3)²: u-тип 4/3, d-тип 1/3; (п2) по недостающей доле, 3·((3 − k)/3)²: u-тип 1/3, d-тип 4/3; (п3) поровну, одна ось-метка, 3·(1/3)² = 1/3.
