# Общая система: α, сильная и слабая связь, массы лептонов в Структуре W

16 ноября 2026. Теория: Hrachya Danielyan. Метки: [данные], [автор], [вывод], [кандидат], [открыто]. Номера — по матрице `claude/system/matrix.json`.

## 1. Общие переменные

| Переменная | Смысл в W |
|---|---|
| N | шагов в цикле обхода части; масса ∝ 1/N (В-17), радиус обхода R ∝ N |
| β | доля шага на перенос (А-39: β² + ι² = 1) |
| P = L/N | путь перехода между равноправными сторонами, в циклах переходящей части |
| k | отношение «общие акты / движение» в связанной системе |
| λ_F | постоянная длина слабого перехода |

## 2. Один механизм — три вида связи [вывод, В-170, В-175, В-176]

Всякая связь — переход восьмёрки между равноправными сторонами (одна сторона, другая, обратно; А-26).

| Связь | Вторая сторона | Путь | Стык |
|---|---|---|---|
| электромагнитная (атом) | другой конец протона | в обход (насквозь нельзя) | раз за переход |
| сильная (ядро) | соседняя тяжёлая часть | прямой | всё время |
| слабая (распад) | нет | некуда — уход | однократно |

## 3. Уравнения

| № | Уравнение | Основание |
|---|---|---|
| 1 | β² + ι² = 1 | А-39 |
| 2 | за переход отстаёт один цикл, он общий: K(1 − ι) = 1 | А-45, В-158 |
| 3 | β = 2/P — доля переноса через путь перехода в циклах | В-170, В-172 |
| 4 | атом: P_a — восьмёрка из двух петель в обход; k_a = 2 | В-170 |
| 5 | ядро: P_d — прямой путь; k_d — своё | В-173, В-175 |
| 6 | m_x/m_e = N_e/N_x; формы: e — 1 восьмёрка, μ — 2 крестом, τ — 3 | В-17, А-07 |
| 7 | распад: доля за цикл = (λ_F/R)⁴/(192π³), λ_F одна для всех | В-176 |

## 4. Решение по данным

Неизвестные: P_a, P_d, N_μ/N_e, N_τ/N_e, λ_F/R_e — пять. Независимых данных: α, размер дейтрона, m_μ/m_e, m_τ/m_e, время жизни мюона — пять.

| Неизвестное | Значение | Из каких данных |
|---|---|---|
| P_a | 274,07 цикла (по 137,04 на петлю) | α |
| P_d | ≈ 10 циклов (β_d ≈ 0,20) | размер дейтрона; оценка |
| N_e/N_μ | 206,77 | масса мюона |
| N_e/N_τ | 3477,2 | масса тау |
| λ_F | 6,74·10⁻¹⁹ м | время жизни мюона |

[вывод] Система совместна: противоречий нет. Но число уравнений равно числу неизвестных — значения не выводятся, а определяются по данным (калибровка).

## 5. Проверки, которые система проходит

1. [данные + вывод] **Тау по мюону.** Та же λ_F (переход без второй стороны одинаков для всех) даёт время жизни тау 291,1 фс; измерено 290,3 фс (0,3 %).
2. [данные + вывод] **α одна для всех водородоподобных систем.** По W путь перехода в циклах задаётся формой стыка (заряды ±1), а не массами частей. Тогда энергия связи растёт с приведённой массой при той же α:

| Система | W (13,6057 эВ × приведённая масса) | Данные |
|---|---|---|
| водород | 13,5983 эВ | 13,5984 эВ |
| позитроний | 6,8028 эВ | 6,8029 эВ |
| мюоний | 13,540 эВ | 13,539 эВ |
| мюонный водород | 2528 эВ | — |

Обе проверки согласуются со стандартной физикой и не отличают её от W. Они показывают, что система W непротиворечива на данных.

## 6. Что сделает систему переопределённой (то есть даст числа)

Недостающее — два правила уровня 2, оба на одну тему: длина пути в циклах.

1. [открыто] **Путь перехода P как функция формы стыка.** Обход (атом) — 274,07; прямой (ядро) — ≈ 10. Правило должно давать оба числа из формы.
2. [открыто] **Длина цикла N как функция формы частицы.** Одна восьмёрка — e, две крестом — μ, три — τ. Прецедент (Барут, через α): μ 206,55 (−0,10 %), τ 3495 (+0,52 %) — существование связи «масса = f(α, число восьмёрок)» данные допускают.
3. [открыто] **λ_F** — постоянная длина слабого перехода; порядка размера W-бозона, бозоны W, Z в W не описаны.

Если правила 1 и 2 найдены, система из семи уравнений с пятью данными становится переопределённой: α, обе массы и время жизни мюона должны выйти без подбора, а размер дейтрона и тау — проверками.

## 7. Итог

- Шесть параметров (α, сильная, слабая, массы e, μ, τ) — в одних переменных, одним механизмом перехода восьмёрки.
- Система совместна; числа пока калибруются по данным.
- Вывод чисел требует одного: правила длины пути в циклах (уровень 2). Это одна задача, а не шесть.

## 8. Массы по форме: проверка семейства правил (16.11.2026)

Программа `mass_rules.py` (признаки форм и семейство записаны в её заголовке до запуска), вывод `mass_rules_output.txt`.

Признаки форм: число восьмёрок, точек, петель, мерность, кресты, общие петли, присоединённая точка, противоположный крест. Семейство: m/m_e = 1 + (1/α)·(a·g + b·h), g и h — две функции из 130 (степени признаков до 4-й, попарные произведения, сумма Барута Σk⁴). a, b — по мюону и протону; электрон обязан давать m_e. Предсказываются τ, n, π±, π⁰.

[расчёт] Перебрано 1971 допустимая пара — ни одна не даёт все четыре в пределах 1 %; лучшая ошибается на 24 %. Семейство «масса = электрон × (1 + форма/α)» с аддитивным вкладом признаков исключено.

[вывод из данных] Причина видна по данным: вклад добавленной восьмёрки зависит от того, как она присоединена.

| Присоединение | Пример | Прибавка массы, m_e |
|---|---|---|
| крест к восьмёрке | e → μ | 205,8 (≈ 1,50/α) |
| через общую петлю | две восьмёрки → p | 1835,2 |
| через точку, перпендикулярно | p → n | 2,5 |
| точка к кресту | μ → π± | 66,4 |
| крест из противоположных | μ → π⁰ | 57,4 |

Восьмёрка, присоединённая крестом или общей петлёй, увеличивает массу в сотни и тысячи раз; та же восьмёрка через точку (нейтрон) — на 2,5 массы электрона. Правило массы должно зависеть от вида соединения, а не только от числа частей.
