## Где в цепочке длина спада

В-286 (2): вызванная форма обходит петли по очереди (А-84), за шаг поворачивает на a/r; запас изменения делится по квадратам (А-39), поэтому мера потери направления — средний квадрат поворота: λ = 1/√⟨k²⟩ = R·√(x(1−x)), k = 1/r.

Слабое место этого прочтения: в нём не сказано, **какая часть поворота** считается потерей. Форма меняет ориентацию во всех направлениях (А-82, В-283 п. 3), пространство трёхмерно, а по А-39 изменение делится по квадратам — на три оси поровну, ни одна не выделена (А-31). Именно так в В-304 получена доля оси 1/3 (заряды), в В-312 — |s|² = 3·(½)².

## Прочтения (закрытый список)

λ = f·R·√(x(1−x)), то есть ⟨k²⟩ потери = ⟨k²⟩/f².

- **L1, f = 1** — потеря — весь поворот (как сейчас).
- **L2, f = √3** — гасит только составляющая поворота вдоль линии заряд — точка (одна ось из трёх): ⟨k²⟩/3.
- **L3, f = √(3/2)** — только две составляющие поперёк этой линии: ⟨k²⟩·2/3.
- **L4, f = √2** — поворот лежит в плоскости петли (две оси), потеря — одна из двух: ⟨k²⟩/2.
- Отброшено до счёта: f = 2 (радиус петли = расстояние O–A) — противоречит А-80: расстояние между партнёрами — диаметр окружности акта.

Края: E(f) = −2,1037 + ln f. Всё остальное — как в Р-91 (S3, κ = 2/(3π), 1/q₀² = 66,29 ± 0,14, части кварков Rb, без W-бозона).
