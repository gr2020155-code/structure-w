# Глобальные восьмёрки на малых системах — формализация записана до запуска (18.11.2026)

Вопрос (В-162): единственна ли расстановка глобальных восьмёрок всех точек, и подавляет ли она возвраты к тому же партнёру (В-247: при случайном выборе возврат в 1/14,8 актов; у электрона одно замыкание на 2,4·10²² тактов).

## Положения

А-03 (обмен местами соседей), А-43 (каждая точка обменивается в каждом такте), А-47 (каждая точка проходит через всё целое и возвращается; её глобальная восьмёрка — петли «из O в O» размером со всю восьмёрку), А-48 (путь каждой точки задан её глобальной восьмёркой), А-40 (возврата нет), А-41 (повтор той же пары — не изменение), В-160 (встречность — следствие обмена), определение восьмёрки (две петли противоположной ориентации), P16 (мест без решётки).

## Формализация (мои выборы)

- F1. Места: пуассоновское облако из n точек в квадрате (2D) или кубе (3D), соседи — Делоне. O — место, ближайшее к центру.
- F2. В каждом такте — совершенное паросочетание графа: каждая точка в одном обмене (А-43). n чётно.
- F3. Обмен: две точки меняются местами по ребру (А-03). Встречность В-160 выполняется сама.
- F4. Период T = 2n: через T тактов каждая точка на своём исходном месте (А-47, «возвращается»).
- F5. Каждая точка бывает в O ровно 2 раза за период: две петли «из O в O» (А-47). При T = 2n это наименьший период: O принимает одну точку за такт.
- F6. Петли одной точки противоположной ориентации. 2D: ориентированные площади относительно O разного знака. 3D: векторы площадей с отрицательным скалярным произведением.
- F7 (вариант «б»). «Размером со всё целое»: каждая петля проходит хотя бы через одно граничное место (вершину выпуклой оболочки).
- F8. В среде возврата нет: ни одно ребро не работает два такта подряд (по кругу периода).

Периодичность на неизменном графе — идеализация: по А-44 целое разворачивается, и точного повтора нет.

## Вопросы

- Q1. Есть ли решения F1–F8 (и F1–F7 без F8)? При каких n?
- Q2. Сколько их с точностью до сдвига времени и обращения (отличные решения = расстановка не единственна).
- Q3. Возвраты: наименьшее и наибольшее число повторов пары (ребро два такта подряд) при F1–F7 на точко-такт, против случайных паросочетаний того же графа.

Единственность (Q2) — проверка А-42 и В-162; Q3 — проверка «масса задаётся глобальным устройством» (В-247). Число 1/137 и массы не используются.

Если сторону задаёт ориентация петли точки, без противоречия она задана только тогда, когда у партнёров в этом такте петли одной ориентации. Если F9 невыполнимо, наименьшая доля актов с противоречием — кандидат на «некомпенсированную долю». Сравнить с q = 0,0854 только после счёта, и только при условии, что доля не зависит от n и расстановки (иначе исключено по той же причине, что в В-225).

## Дополнение, записано до запуска FS (18.11.2026, после положений автора А-74 — А-76)

- FS1 (А-74, точная симметрия мест). 2D: места симметричны относительно прямой через O. На прямой — O и ещё одно место, остальные — зеркальные пары (n чётно). Соседи — рёбра Делоне, зеркальный образ которых тоже ребро Делоне.
- FS2 (А-74, точная симметрия восьмёрки). Вторая петля каждой точки — зеркальная копия первой: через n тактов каждая точка стоит в зеркальном образе своего места, pos(t + n) = σ(pos(t)). Отсюда сами собой равная длина петель (F10) и противоположная ориентация (F6).
- Остальное — F2–F5, F8, как раньше.
- Вопрос по А-76 (единственность целого): есть ли симметричные расстановки ровно с одним решением (с точностью до сдвига времени и обращения), и что у них общего.
- Вопрос по А-73 и А-75: у каждого решения посчитать число различных путей и встречные пары.

### Итог первого запуска FS и поправка, записано до второго запуска

Три симметричных облака n = 8 (O и ещё одно место на прямой, 3 зеркальные пары) — решений нет, решатель доказал за 1–2 с. Причина — чётность, и она точная. Каждый такт — совершенное паросочетание, то есть n/2 перестановок пар мест; за n тактов перестановка мест чётна (n·n/2 = 2m², n = 2m). FS2 требует, чтобы за n тактов вышла зеркальная перестановка σ, а она меняет местами k зеркальных пар и имеет чётность k. Значит, FS2 возможно только при чётном k. При n = 8 и двух местах на прямой k = 3 — невозможно.

FS1′: число мест на прямой выбирается так, чтобы k было чётным. n = 8 — четыре места на прямой (k = 2); n = 10 — два (k = 4).
