# Правила счёта: правило X для целых из фрагментов креста и тау-формы (27.11.2026)

Записано и отправлено на GitHub ДО счёта. Программа: `hadron_x.py`, запись — Р-145. Автор: «запиши ветки правила X из положений и посчитай их по правилам, заранее отправленным на GitHub».

## Основа

**Лестница** (В-184, В-186): m/m_e = 1 + (3/2)·(1/α)·X, 1/α = 137,036.

**Положения, из которых строятся ветки:**
- **Поколение g** — число восьмёрок у O (В-305): g = 1 — одна восьмёрка, 2 — крест, 3 — тау-форма.
- **Прибавка формы поколения** по закону плоскостей (В-186): X_lep(g) = Σ_{j<g} j⁴, то есть 0, 1, 17.
- **Кварк** — фрагмент из k осей формы своего поколения (В-304, В-406 п. 4): d, s, b — k = 1; u, c, t — k = 2.
- **Доля оси:**
  - 1/3 (В-304);
  - по квадратам — (k/3)² (А-39);
  - вес гашения — C(3, k)·(k/3)², то есть N_c·Q² (В-304).

## Целые (данные Д-88, PDG выпуск 2026, прочитано 27.11)

**Основной набор** (засчитывается): целые из одинаковых фрагментов одного поколения и одной ориентации.

| Целое | Состав | m, МэВ | База (то же целое из фрагментов 1-го поколения) |
| --- | --- | --- | --- |
| Ω⁻ | sss | 1672,43 | p (uud) 938,272 |
| φ | ss̄, спин 1 | 1019,460 | ω (спин 1) 782,66 |
| J/ψ | cc̄, спин 1 | 3096,900 | ω |
| Υ(1S) | bb̄, спин 1 | 9460,40 | ω |

**Почему так.**
- База — измеренная масса того же целого из фрагментов 1-го поколения (протон, ω). Так ветка проверяет только член фрагментов, а не устройство целого.
- Для мезонов в W правила устройства нет. Пион (крест + точка, В-201) — другой вид соединения.
- У фрагментов 1-го поколения X_lep(1) = 0, поэтому у базы член фрагментов равен 0 во всех ветках.

**Для сравнения** (не засчитывается): Λ (uds) 1115,683; Σ⁰ (uds) 1192,642; Ξ⁻ (dss) 1321,70; Ξ⁰ (uss) 1314,82; K± 493,677; D⁰ 1864,84; D_s 1968,35; B_s 5366,91; B_c 6274,47; η_c (cc̄, спин 0) 2984,09; η_b (bb̄, спин 0) 9398,7. Спин 0 против спина 1 правилом не различается — нужен закон для спина, в положениях его нет (В-348 даёт только 0 или 1).

## Ветки (без подогнанных чисел)

**Аддитивные:** X(целое) = X(база) + Σ по фрагментам [f(k, g) − f(k′, 1)], где f(k′, 1) = 0.

| Ветка | f(k, g) | Прочтение |
| --- | --- | --- |
| A1 | X_lep(g) | фрагмент несёт всю прибавку своей формы |
| A2 | (k/3)·X_lep(g) | доля осей |
| A3 | (k/3)²·X_lep(g) | доля осей по квадратам (А-39) |
| A4 | C(3, k)·(k/3)²·X_lep(g) | вес гашения N_c·Q² (В-304) |

**Множительные:** X(целое) = X(база)·Π по фрагментам [1 + f(k, g)]^(1/n), где n — число фрагментов.

| Ветка | f(k, g) |
| --- | --- |
| M1 | X_lep(g) — целое «сидит» на форме поколения |
| M2 | (k/3)·X_lep(g) |

## Критерий (решён заранее)

Ветка проходит, если все 4 целых основного набора попадают в 1 % по массе: это порядок α, как отклонения лестницы (до 0,81 %, В-184).

## Проверка без ветки (диагностика, не засчитывается)

Из данных вычисляется член одного s-фрагмента:
- аддитивный: (X(Ω) − X(p))/3 и (X(φ) − X(ω))/2;
- множительный: (X(Ω)/X(p))^(1/3) и (X(φ)/X(ω))^(1/2).

Если барионы и мезоны требуют разного члена на один и тот же фрагмент, то никакое правило «член фрагмента + устройство целого» без взаимодействия не работает, при любых числах.

## Честно: что я знаю до счёта

**Прикинул в уме:**
- Все шесть веток не проходят, промахи от ~3 % до десятков процентов.

**Заметил заранее (не строю на этом ветку):** m(J/ψ)/m(φ) ≈ 3,04 и m(Υ)/m(J/ψ) ≈ 3,05 — отношение около 3, как число осей. Оно не попадает ни в одно поколение (s, c — одно поколение, b — другое) и в ветки не входит.
