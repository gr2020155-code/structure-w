# Правила счёта: варианты для напряжения Хаббла внутри W (27.11.2026)

Записано и отправлено на GitHub ДО счёта. Программа: `hubble_variants.py`, запись — Р-136. Автор: «Посчитай варианты. Но с напряжением Хаббла это не связано с красным смещением в нашей интерпретации?»

## Что сравнивается

Х-13 — это расхождение двух линеек:
- **близкая линейка:** свечи (цефеиды → сверхновые) и красное смещение близких галактик дают h = 0,735;
- **дальняя линейка:** звук до отрыва света (r_s, В-392) по углу реликта требует h ≈ 0,685.

Обе линейки используют красное смещение одинаково: 1 + z = k₀/k (В-374).

## Варианты

**В0 — средний темп по линейке звука без реликта.**
- Линейка (Д-80) задаёт форму (Ω_m) и масштаб b = (c/H₀)/r_d.
- r_d — звук до отрыва восьмёрок от света: drag, где ∫ dτ/R = 1. Считается тем же счётом, что в Р-135 (ν1, F = 1,14, b1/b2).
- Отсюда h. Это второй, независимый от реликта, замер дальнего темпа.

**В1 — местная доля красного смещения (вопрос автора, А-99).**
- Общего «сейчас» нет. Значит, такт у нас k_loc не обязан равняться среднему k₀.
- Тогда для любого источника 1 + z_набл = (k_loc/k₀)·(1 + z) = (1 + ε)(1 + z).
- Добавка ε одинакова для всех источников. Для близких она весит много (H₀ завышается), для далёких и реликта — ничтожно.
- Подгонка по сверхновым (калибраторы с расстояниями по цефеидам + все z > 0,01, полная ковариация): числа h, ε, M. В D_L множитель (1 + z_набл).
- Отдельно: подгонка с h = 0,685 при свободных ε и M.

**В2 — местная зона другого темпа (А-106: плотность связей вокруг нас иная).**
- Темп g(z) = g_far(z)·(1 + A·S(z)), где S = 1/(1 + exp((z − z_v)/(0,1·z_v))).
- Сетка z_v = 0,03; 0,05; 0,1; 0,15; 0,3; 0,5. Выбор лучшего из шести — раскрываю (поиск по сетке).
- Те же сверхновые. Подгонка с h_far = 0,685 при свободных A и M.

**В3 — ещё одна доля в начале (А-105: квадрат темпа — сумма долей).** При h = 0,7354:
- **(а)** доля, растущая как свет (u⁻⁴), не связанная со звуком: Ω_r → Ω_r·(1 + f);
- **(б)** доля u⁻⁶: q — её отношение к свету при 1 + z = 1101.
- Подбирается f (или q) для точного θ. Затем проверка: даёт ли эта же доля r_d, нужный линейке при h = 0,7354.
- Мост: перевод D/H → Ω_b·h² при другой доле в первые минуты не пересчитываю (раскрываю).

## Критерии (решены заранее)

- **База:** сверхновые без ε и без зоны, свободны h и M, χ²₀.
- **В0:** сообщаю h ± σ (σ — от масштаба линейки при Δχ² = 1 и от Ω_b·h²). «Согласуется с реликтом», если |h − 0,685| ≤ 2σ. Расхождение с 0,735 — в σ.
- **В1:** проходит, если χ²(h = 0,685; ε, M свободны) − χ²₀ ≤ 4. Число свободных чисел то же, что в базе.
- **В2:** проходит при каком-либо z_v, если χ²(h_far = 0,685; A, M свободны) − χ²₀ ≤ 4.
- **В3:** проходит, если |b_модель − b_линейка| ≤ 2·√(σ_b² + σ_h²), где σ_h — сдвиг b_модель от h ± 1σ.
