# Сколько элементов замыкают петлю следующего уровня — правила до расчёта

17 ноября 2026. Теория: Hrachya Danielyan. Номера — по `claude/system/matrix.json`.

## Задача

По кандидату В-217: 1/α — число обходов уровня ниже в одной петле уровня выше. Найти это число из правил структуры, без данных.

## Правила

| № | Правило | Основание |
|---|---|---|
| Л1 | Петля уровня выше составлена из элементов уровня ниже; каждый W уровня ниже — атом уровня выше | А-26 |
| Л2 | Соседние элементы петли — противоположного направления (одноимённые рядом — противоречие) | В-175, В-192 |
| Л3 | Петля замкнута; отношение пути к поперечнику (π) — рациональная дробь, задаётся замыканием | А-51 |
| Л4 | Все элементы петли равноправны | А-31 |
| Л5 | Отношение уровней одно для всех уровней | А-26 |
| Л6 | Один обход элемента — отставание на один обмен | А-60, В-212 |

## Проверка до запуска [вывод]

1. Л2 требует чётного числа элементов: при нечётном два соседа замыкания одноимённы.
2. Л1, Л3, Л4 выполняются при любом чётном числе, начиная с наименьшего кольца (4–6 элементов в расстановке без решётки, где у места в среднем около 15 соседей).
3. Л5 требует, чтобы число было одним для всех уровней, но не задаёт, каким.
4. Л6 переводит число в отставания: за петлю уровня выше — 1/α отставаний уровня ниже. Это то же отношение, которое ищется, а не новое условие.

Итог: правила Л1–Л6 допускают любое чётное число. Верхней границы и выделенного значения нет. Расчёт модели с этими правилами вернул бы то, что задаст добавленное извне ограничение, — запуск отложен.

## Недостающее [открыто]

Что по структуре ограничивает размер петли следующего уровня: почему она не из 4 элементов (наименьшее кольцо) и не из 1000, а из ≈ 137 обходов. Это та же «сила стыка» (В-215), записанная на языке уровней: размер петли перехода в обходах лёгкой части и есть 1/α.
