# Правила счёта: размер глобального обхода из B против повторов на реликте (28.11.2026)

Записано и отправлено на GitHub ДО счёта. Программа: `loop_size.py`, запись — Р-157. Автор: «Проверь оба варианта».

## Что проверяется

Если связь даёт одно новое различие за один глобальный обход точки (А-47), то √B = 1/L (L — длина обхода в шагах; за такт — шаг). В сегодняшних шагах L = c/(H₀·√Ω_B).
- **Вариант 1.** За обход L — петля нашей половины (одна петля из O в O). Окружность нашей вселенной L₁ = c/(H₀·√Ω_B).
- **Вариант 2.** За обход L — вся восьмёрка (обе половины, А-108). Окружность нашей половины L₂ = L₁/2.

**Условие C (без него проверка не применима).** Петля — замкнутый путь в трёхмерном пространстве, по которому идёт свет (шаг за такт). Тогда источник виден с двух сторон петли, а сфера, с которой приходит реликт, пересекается со своими копиями — на реликте должны быть пары одинаковых окружностей.

## Как считается

- Путь света реликта в сегодняшних шагах: D* = ∫₀^z* dz/g, z* = 1090 (как в Р-135; от ±10 итог не зависит). Кинематика В-374, закон А-105 с постоянным B (В-426): Ω_m = 0,2973, Ω_r = 4,57·10⁻⁵, Ω_B = 0,7027 (Р-156).
- Отношение L/D* от h не зависит: и L, и D* ∝ 1/H₀. Для сравнения — в Гпк и млрд световых лет при h = 0,7354 и 0,687.
- Сколько раз свет от начала обошёл бы петлю: D_h/L, где D_h = ∫₀^∞ dz/g (не засчитывается).

## Данные

**Д-94.** Planck 2015, XVIII (arXiv:1502.01593), поиск повторов по температуре и поляризации: нет признаков замкнутого пространства с размером меньше диаметра сферы реликта. Радиус наибольшего шара, вписанного в повторяющуюся ячейку: R_i > 0,97·χ_rec для кубического тора (и по поиску одинаковых окружностей — 99 %, по одной поляризации) и R_i > 0,56·χ_rec для «слоя» (замкнуто одно направление). Отношение к χ_rec — геометрия путей света, оно переносится в W как отношение к D*. Предел для слоя получен по правдоподобию относительно официальной модели — мост, модельный; поиск окружностей — геометрический.

## Критерий

Одна замкнутая петля — это «слой»: R_i = L/2. Вариант проходит, если L/2 ≥ 0,56·D*, то есть L ≥ 1,12·D* (мягкий предел). Для сравнения — кубический тор: L ≥ 1,94·D*.
