# Магнитный момент составной формы — правила записаны до сравнения (18.11.2026)

Задача: получить из форм W отношение μ_n/μ_p (данные −0,68498) и аномалию протона (1,793) без подбора.

## Что уже записано в положениях

- В-14 [вывод]: магнитный момент частицы — обход её заряда, μ = e·v·R/2.
- В-12, W3 [кандидат, отобран данными]: узор идёт по обходу со скоростью c.
- P8 (А): радиус обхода R = ħ/(Mc), M — масса всей формы.
- В-198 [вывод]: форма движется целиком.
- В-10, В-34 [вывод]: вклады петель ядра противоположной ориентации гасятся; ядро в 10⁴–10⁷ раз меньше обхода.
- А-23: протон — петли A–P₁ (+), P₁–P₂ (−), P₂–C (+); замыкание — обмен P₁↔P₂ (А-10).
- А-52: нейтрон — протон (+, −, +) и восьмёрка электронного типа (+, −) через точку в перпендикулярной плоскости; точка — не элемент замыкания (В-201).
- А-55: у протона замыкание — петля, у лептонов — точка. А-15: заряд — направление петли.
- В-202 [кандидат]: элемент замыкания, общий двум восьмёркам, переходит между ними (у мюона — точка O, у протона — двойная петля P₁↔P₂).

## Правила (записаны до счёта)

**М0 — только записанное.** Каждая форма — один обход своего полного заряда Q: μ = Q·eħ/(2M). Внутренних токов на масштабе обхода нет.

**М1 — прочтение В-202 (кандидат).** К М0 добавляется ток перехода элемента замыкания между восьмёрками. Он несёт заряд только если элемент — петля (А-15, А-55). Его величина зависит от пути перехода, а путь не записан. Поэтому М1 проверяется только по знаку и порядку величины.

**Спин.** Отношения моментов составных частиц зависят от того, как складываются спины их частей. В W спин ½ одной восьмёрки — кандидат (правило 2:1, В-27). Правила сложения спинов восьмёрок с общим элементом нет (В-36, В-42), а для одной восьмёрки открыто противоречие ħ против ħ/2 (В-31).

## Проверки (что сравнивать с данными)

1. М0: μ_p и μ_n.
2. М1, лептоны: замыкание — точка, тока перехода нет, аномалия только порядка α (е, μ, τ).
3. М1, протон: замыкание — петля, аномалия порядка 1.
4. М1, нейтрон: дираковская часть 0 (полный заряд 0). Ток перехода протонной части не меняется: восьмёрка присоединена через точку, не через элемент замыкания. У восьмёрки замыкание — точка, своего тока перехода нет. Значит, μ_n = κ_p. Сравнить знак с данными.
