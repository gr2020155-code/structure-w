# Сужение полосы 1/α: правила, записанные до счёта (25.11.2026)

Полоса В-295 (135,7–138,2) складывается из двух неточностей: (а) адронная часть — массы лёгких кварков как размеры форм; (б) расстановка мест — разброс q₀ около 2 %.

## (а) Адроны: заменить массы лёгких кварков измеренным ходом α

Дальше расстояния r_Z = ħ/(M_Z·c) = 2,164·10⁻¹⁸ м ход α измерен целиком, адроны включены: 1/α(M_Z) = 128,9 в «эффективном» определении (Д-48, по энергии). Перевод в реальное расстояние для логарифмического хода: 1/α(r_Z) = 1/α(M_Z) + κγ·n, где n = ΣN_cQ² видов, работающих на r_Z: e, μ, τ, u, d, s, c, b, то есть n = 3 + 11/3 = 20/3. Это та же поправка γ, что в Р-61; для лептонов она проверена (3,94 против 4,31).

Сравнение на r_Z без масс лёгких кварков:

1/α_W(r_Z) = 1/q₀² + κ·(20/3)·ln(r_Z/a) + κ·(4/3)·[ln(D_t/a) − 2,1037]

Справа нет ни одной массы, кроме t; ниже r_Z работают все восемь видов с выведенным наклоном (В-289), у t — свой край (В-286). Слева — данные. Неточность данных при 128,9: около ±0,05.

## (б) Расстановка мест

Положения: А-27 — без решётки, изотропно; А-06 — размер точки один шаг, промежутков между точками нет; А-76 — места ограничены непротиворечивостью. Пуассоновское облако даёт сгустки и пустоты разного размера; «промежутков нет, размер один шаг» ближе к облакам с запретом сближения (точки не ближе некоторого d). Считается то же правило Р-52 (А-70) на облаках Матерна II (пуассоновские точки с метками; точка остаётся, если в радиусе d нет точки с меньшей меткой) при двух d: доля оставшихся около 1/2 и около 1/4.

## Критерий

- (а) засчитывается как сужение, если полоса 1/α_W(r_Z) по пуассоновским q₀ уже, чем ±1.
- (б) Если q₀ на облаках с запретом сближения лежит между пуассоновским и решёткой, полоса от расстановки остаётся ±1 %, а выбирать между расстановками по данным — [кандидат, выбрано данными].
