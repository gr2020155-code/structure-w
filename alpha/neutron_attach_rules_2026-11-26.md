# Нейтрон: через какую точку встаёт восьмёрка — правила, записанные до счёта (26.11.2026)

Продолжение В-310. Автор на вопрос «где в нейтроне восьмёрка» ответил «не знаю» (26.11). Положения развилку не решают, поэтому по правилу работы считаются все ветви и выбор делают данные с пометкой [кандидат, выбрано данными]. Свободное расстояние s из В-310 (C2) заменяется точками самих форм — непрерывного параметра нет.

## Что принимается

- Восьмёрка по зарядам слилась с крайней петлёй (В-310 п. 1): нейтрон по осям — (d, d, u).
- В пространстве (А-52: перпендикулярная плоскость) положительный заряд крайней петли +2/3 остаётся в её центре, а заряд −1 восьмёрки — в центре восьмёрки, точке O' (её элемент замыкания, А-10; восьмёрка симметрична, А-07).
- Точки протона: A, P₁, P₂, C на прямой с шагом L (центры петель −L, 0, +L; по протону L = 0,728 фм, Р-79). Шаг между точками восьмёрки тот же L (А-31: одинаковые точки и обмены не различаются по размеру).

## Развилки (список закрыт, 4 сочетания)

- T — общая точка на протоне (обе принадлежат крайней петле, с которой слилась восьмёрка): T1 — крайняя точка A (x = −1,5·L); T2 — внутренняя P₁ (x = −0,5·L).
- G — какая точка восьмёрки общая: G1 — её центр O' (тогда центр восьмёрки в общей точке); G2 — её крайняя точка A' (центр O' на расстоянии L от общей точки, перпендикулярно прямой).

⟨r_n²⟩ = Σ Q·r² от центра протонной прямой: (+2/3)·L² [крайняя петля] + (−1/3)·0 [средняя] + (+2/3)·L² [другая крайняя] + (−1)·r_O'².

## Критерий

Главное — **знак** (данные: минус, Д-60). Точечные заряды грубы, поэтому величина сообщается для порядка, отношение к протону сравнивается с −0,163 без требования совпадения. Ожидание до счёта: общая точка у края (T1) даёт минус при любом G; внутренняя (T2) — плюс. Если данные выберут T1, это кандидат «восьмёрка встаёт к краю нейтрона», выбранный данными, а не выведенный.
