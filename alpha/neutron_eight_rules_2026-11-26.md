# Нейтрон по А-52: куда встаёт восьмёрка — правила, записанные до счёта (26.11.2026)

Автор: «не знаю, разберём» (26.11). Задача — понять, как картина А-52 (нейтрон = протон + восьмёрка электронного типа через точку в перпендикулярной плоскости) согласуется с данными, если восьмёрка как отдельная часть магнитного момента не проходит ни в одном прочтении (В-309).

## Данные (две независимые проверки)

- Д-50: μ_n = −1,913 μ_N, μ_p = 2,793 μ_N.
- Новое: средний квадрат зарядового радиуса нейтрона ⟨r_n²⟩ = −0,1155 ± 0,0017 фм² (PDG); протон r_p = 0,8408 фм, ⟨r_p²⟩ = 0,7069 фм². Знак минус: отрицательный заряд нейтрона в среднем дальше от центра, чем положительный. Отношение ⟨r_n²⟩/⟨r_p²⟩ = −0,163.

## Положения

- А-07, А-23: протон — точки A–P₁–P₂–C на прямой, петли A–P₁ (+), P₁–P₂ (−), P₂–C (+).
- В-305: доли петель +2/3 (две оси), −1/3 (одна ось), +2/3.
- В-304: фрагмент — от 0 до 3 осей; электрон — все три оси со знаком «−».
- А-52: восьмёрка проходит через одну точку протона в перпендикулярной плоскости.
- Принцип автора «не лего»: часть, к которой присоединилась восьмёрка, — одно новое состояние, а не сумма.

## Шаг 1 — вывод до счёта: к какой петле может встать восьмёрка

Если восьмёрка сливается с петлёй (оси складываются со знаком), петля «+2/3» (две оси «+») и восьмёрка (три оси «−») дают одну ось «−» = −1/3: петля становится d. Петля «−1/3» с восьмёркой дала бы четыре оси «−» — больше трёх, по В-304 невозможно. Значит, восьмёрка встаёт только к петле «+», то есть к крайней (A–P₁ или P₂–C); через внутреннюю точку P₁ или P₂ она тоже может слиться только с крайней петлёй. Итог: нейтрон = (d, d, u) по порядку вдоль прямой — новая d с краю, прежняя d в середине. Для магнитного момента это сочетание N2 из Р-78 (−2,00 μ_N при S3·R2).

## Шаг 2 — распределение заряда (список закрыт)

Модель: заряд петли — в середине её отрезка; центры петель на −L, 0, +L; ⟨r²⟩ = Σ Q_i·x_i² от центра формы (форма вращается — среднее по направлениям то же). Протон: (2/3 + 2/3)·L² = (4/3)·L²; по ⟨r_p²⟩ L = 0,728 фм.

- C1 — слияние полное: заряд −1/3 в центре крайней петли. ⟨r_n²⟩ = (−1/3 + 2/3)·L² = +(1/3)·L².
- C2 — слияние по осям, но в пространстве восьмёрка своя (А-52: перпендикулярная плоскость): крайняя петля остаётся +2/3 на своём месте, заряд −1 восьмёрки — на расстоянии s от точки присоединения перпендикулярно прямой. ⟨r_n²⟩ = (2/3 + 2/3 − (1 + s²))·L² − (1/3)·0 = (1/3 − s²)·L². Знак минус при s > 1/√3 ≈ 0,577·L. s в положениях не задано — свободный параметр; сообщается, какое s нужно данным, и это не проверка.
- C3 — контроль, не из А-52: «зеркальный» нейтрон (d, u, d) — d по краям. ⟨r_n²⟩ = (−1/3 − 1/3)·L² = −(2/3)·L².

Точечная модель груба (петли — не точки), поэтому критерий — только **знак** ⟨r_n²⟩; величина сообщается для порядка.

## Критерий

Прочтение проходит, если даёт отрицательный ⟨r_n²⟩ без свободного параметра и μ_n < 0 (при S3·R2 — у всех трёх −2,00, магнетизм их не различает). Ожидание до счёта: C1 не проходит по знаку; C2 проходит только при подобранном s; C3 проходит по знаку, но не следует из А-52. Если так — решение за положением автора: где в нейтроне стоят отрицательные части.
