# Вес деления и длина спада из положений: правила, записанные до счёта (25.11.2026)

Задача (В-285 п. 5): получить из положений (а) вес деления восьмёрки x(1−x) и (б) длину спада R·√(x(1−x)), не беря их из разложения данных.

## Форма

Вызванная зарядом форма — восьмёрка (А-07, А-12), её диаметр D = 2R (А-80) — n шагов. Точка замыкания O (А-10) делит диаметр на две петли: n_A и n_B = n − n_A шагов, диаметры n_A·a и n_B·a.

## (а) Вес: правило счёта конфигураций

- Форма — это выбор партнёра в каждой петле: обмены O↔A и O↔B (А-07). Конфигураций с данным делением — n_A·n_B (каждая точка петли A с каждой точкой петли B).
- Все конфигурации неразличимы по весу (А-31). Значит, вес деления ∝ n_A·n_B, то есть x(1−x).
- Контрпример для сравнения (считается тоже): вес 1 на каждое деление (положение O равновозможно, без счёта пар).

## (б) Длина спада: правило «по квадратам»

- Форма обходит петли по очереди: один обход — одна петля (А-84). Скорость — шаг за такт (В-12), поэтому доля времени в петле равна доле её длины: x и 1−x.
- За шаг в петле радиуса r форма поворачивает на долю a/r.
- Запас изменения за шаг делится по квадратам (А-39). Значит, мера потери направления за шаг — среднее по времени от квадрата поворота: ⟨(a/r)²⟩ = x·(a/r_A)² + (1−x)·(a/r_B)².
- Длина спада λ = a/√⟨(a/r)²⟩, гашение на расстоянии r от вызванной формы падает как exp(−r/λ): постоянная доля потерь на шаг (по А-20 — доля конфигураций).
- Контрпример для сравнения (считается тоже): линейное среднее поворота, λ = a/⟨a/r⟩.

## Счёт

Для n = 2000 шагов: перебор всех делений n_A = 1…n−1, четыре сочетания (вес: пары или 1) × (среднее: квадратов или линейное). Для каждого: ln(r_eff/D) = E[ln(λ/D)] − γ, место половины наклона. Данные: −2,1037 и 0,150·D.

## Критерий

- Сочетание «пары × квадраты» обязано дать данные, если правила верно воспроизводят разложение Р-64. Оно и проверяется: правила записаны из положений, а не из формулы.
- Остальные три сочетания показывают, решают ли данные между прочтениями.
- Слабые места, которые остаются: (1) чтение А-31 как «вес = число пар партнёров»; (2) чтение А-39 как «потеря направления за шаг — среднеквадратичный поворот»; (3) почему спад именно экспоненциальный — по А-20 это доля конфигураций, и её надо будет вывести.
