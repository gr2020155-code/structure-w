# Край гашения как пара петель: правила (25.11.2026)

Порядок работы с 25.11: развилки решаются по положениям, а где они не решают — по данным; выбранное данными помечается [кандидат, выбрано данными].

## Что уже проверено до этих правил (математика, не структура)

Профиль данных (потенциал Юлинга, w — доля полного наклона на расстоянии r, ρ = r·mc/ħ = r/R) точно, до 10⁻¹⁰, раскладывается на сумму экспонент:

w(ρ) = ∫₀¹ 6x(1−x) · exp(−ρ/√(x(1−x))) dx.

Читается так: пара из двух частей с долями x и 1−x, вес пары ∝ x(1−x), у каждой пары своя экспонента с длиной спада λ = R·√(x(1−x)). Экспонента — постоянная доля потерь на шаг. Отсюда эффективный край: ln(r_eff/D) = E[ln(λ/D)] − γ, где γ возникает из экспоненты (∫(e^(−t) − 1{t<1})dt/t = −γ).

## Прочтение в W (кандидат)

Форма среды, вызванная зарядом, — восьмёрка из двух петель (А-07, А-12). Её размер D (А-80) делится между петлями в долях x и 1−x: радиусы петель xR и (1−x)R.

- Вес x(1−x) — произведение долей. Это то же правило, что β = q·q в атоме (В-228, В-250): перенос — произведение вкладов двух участников.
- Длина спада λ = √(xR·(1−x)R) — среднее геометрическое радиусов петель: квадрат доли потерь на шаг равен произведению долей поворота двух петель за шаг. Это правило «по квадратам» (А-39).
- Потери на шаг — постоянная доля, отсюда экспонента. По А-20 это доля конфигураций, а не вероятность.

## Варианты доли x (список закрыт до счёта)

- S1. Только симметричная восьмёрка, x = 1/2 (А-74: вторая петля — зеркальная копия первой).
- S2. Любое деление равновозможно, вес 1 (без правила произведения).
- S3. Вес x(1−x) — правило произведения, как β = q·q.

Для каждого: ln(r_eff/D), место половины наклона, длина хвоста. Данные: −2,1037, половина на 0,150·D, хвост e^(−2r/R), то есть длина R/2.

## Критерий

S3 совпадает с данными тождественно, потому что разложение взято из данных. Поэтому S3 — [кандидат, выбрано данными], а не вывод. Выводом станет, если правило произведения для деления петель и правило среднего геометрического для длины спада будут получены из положений, а не взяты из разложения.
