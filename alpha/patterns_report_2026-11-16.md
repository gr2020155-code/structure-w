## 1. Кодировка (зафиксирована до подгонки)

### 1.1 Состояние точки
Для каждой точки записано:
- **n** — число прохождений петель через точку за полный цикл. Общая двойная петля считается дважды: она принадлежит двум восьмёркам и за цикл проходится дважды. Присоединённая точка получает 1 за обмен с хозяином и ещё 1 за каждую петлю, проходящую через неё.
- **d** — мерность замыкания в точке: число независимых осей её петель и связей (1, 2 или 3).
- **роль**: конец / точка замыкания / общая (на общей петле) / присоединённая / двойная.
- **rel** — направления восьмёрок, замыкающихся в точке: одинаковые или противоположные.
- **несёт** — число восьмёрок, продетых через присоединённую точку.

Стык — место, где встречаются восьмёрки или к форме присоединена точка. У стыка те же переменные: d, число петель, число восьмёрок, проходы.

### 1.2 Формы

| Форма | Точки (роль, n, d) | Петли | Восьмёрки | Обоснование |
|---|---|---|---|---|
| e | A кон(1,1), O замык(2,1,противоп.), B кон(1,1) | 2 | 1 | [автор] одна восьмёрка A–O–B, O — замыкание |
| μ | 4 конца (1,1), O замык(4,2,одинак.) | 4 | 2 | [автор] крест двух восьмёрок в O. Направления одинаковые, потому что π± = μ + точка, а у π± восьмёрки одного направления |
| τ | 6 концов (1,1), O замык(6,3,одинак.) | 6 | 3 | [автор] крест + третья восьмёрка перпендикулярно |
| p | A кон(1,1), P1 общ(3,1), P2 общ(3,1), C кон(1,1) | 3 | 2 | [автор] петли A–P1(+), P1–P2(−), P2–C(+); P1–P2 — общая двойная петля, через P1 проходят A–P1 один раз и P1–P2 дважды, отсюда n = 3 |

Новые формы, которые строятся теми же операциями и в подгонке не участвуют: e+точка, p+точка, π⁰+точка, e+восьмёрка через точку, μ+восьмёрка через точку, τ+восьмёрка через точку.

### 1.3 Признаки
Из состояний программа считает 24 целых признака. Каждый берётся как превышение над электроном, поэтому любое правило даёт m_e = 1 точно. Признаки: число точек, петель, восьмёрок; мерность; порядок креста J_c; сумма Барута Σ_{j≤J_c} j⁴ и Σ j²; общие петли и число петель при них; число присоединённых точек, их мерность, мерность хозяина, несомые восьмёрки; двойные точки; противоположные кресты; max n; Σn², Σn^{2d}; число плоскостей при стыках; три признака «умножения по плоскостям» Σ_стыков k^{2d} (k = петли, восьмёрки−1, проходы). Сюда же записано правило автора одним признаком (AuthA): крест → Σ_{j=1}^{d−1} j⁴, общая петля → (число петель)².

### 1.4 Неоднозначности кодировки — сказаны заранее
- Из какой точки протона выходит связь нейтрона и какие у N значения n и d — однозначно из формулировки не следует. Выбрано n_N = 2, d_N = 2.
- Куда присоединена точка в π± — не сказано. Выбрано: к центру креста.
- Как считать «двойную точку» π⁰ — выбрано: два места с n = 2.

При другом выборе числа меняются. Вывод п. 4.3 от этого не зависит: точка N нейтрона и точки креста одинаково двумерны, а вклады у них различаются в 80 раз.

## 4. Лучшие закономерности и их значимость

### 4.1 Лестница μ, τ, p (F1, F2)

[расчёт] m = 1 + (3/2)(1/α)·X: μ −0,10 %, τ +0,52 %, p +0,81 %. Наибольшая ошибка 0,81 %.

Вероятность получить такое качество случайно — тот же перебор на случайных мишенях:

| Нулевая модель | P(наилучшая ошибка ≤ 0,81 %) |
|---|---|
| F1, каждая масса × exp(U(−ln2, ln2)) | **0,0003** |
| F1, каждая масса × exp(U(−0,1, 0,1)) | **0,0015** |
| F1-свободный (любая форма берёт X из всех 31 значения), ×/÷2 | 0,0036 |
| C = 3/2 задано заранее, только τ и p, ×/÷2 / ±10 % | 0,0013 / 0,021 |
| C = 3/2 задано заранее, **только p** (X_p ∈ {k²}), ×/÷2 / ±10 % | **0,023 / 0,083** |
| F2, ×/÷2 / ±10 % | 0,0000 / 0,0003 (см. оговорку ниже) |

Оговорки:
- [вывод] В F2 правило автора есть среди признаков (AuthA), а этот признак составлен после того, как данные были известны. Поэтому P для F2 занижено. Если убрать AuthA, лучший результат 47 748 членов — 81 %: грамматика сама лестницу не находит.
- [вывод] Объём свободы в F1 — моя оценка того, что было доступно при подборе. Реальная свобода больше: формы правил, отвергнутые до этого, тоже были попытками. Поэтому 0,0003 — нижняя граница P.
- [данные] μ = 1 + 3/(2α) (Намбу, 1952; Барут, 1979) и τ = 1 + (3/2α)(1⁴ + 2⁴) — **формула Барута**, PRL 42 (1979) 1251, m_N = m_e(1 + (3/2α)Σ_{n≤N} n⁴). Значит, лептонная часть известна 47 лет. Новое в лестнице — только X_p = 9, и это добавление значимым не является: P = 0,02–0,08.

**Закономерность 1** [расчёт]: массы μ и τ лежат на лестнице Барута 1 + (3/2α)Σ_{j=1}^{N} j⁴. Случайно такое возникает примерно в 0,03–0,4 % случаев. Протон на эту же лестницу (X = 9) встаёт с P ≈ 2–8 % — это на уровне случая.

### 4.2 Единое правило по состояниям точек (F2j, F5): не найдено

- [расчёт] F5 (вклад точки — одна функция h(n, d)): из 33 120 правил ни одно не даёт μ, τ, p каждый в пределах 1 %. Лучшее даёт 18,7 %. На шести мишенях лучшее даёт 77,6 %, и с отдельной шкалой для присоединённых точек (4,6·10⁶ правил) тоже 77,6 %.
- [расчёт] F2j (одно определение k на всех стыках): лучшее даёт 80 %.
- [вывод] Почему так: у лестницы автора k означает разное.

| Форма | Что такое k | Значение |
|---|---|---|
| μ | номер плоскости креста | 1 → 1⁴ |
| τ | номера двух плоскостей из трёх | 1, 2 → 1⁴ + 2⁴ |
| p | число петель, касающихся общей петли | 3 → 3² |

Если тот же счёт применить к стыку протона как к кресту (восьмёрок − 1 = 1), получится X_p = 1. Если применить счёт протона (петли через стык) к кресту мюона (4 петли), получится 4⁴ = 256. В состояниях точек (n, d) этих чисел нет: точка O электрона (n = 2, d = 1) и точки P1, P2 протона (n = 3, d = 1) одномерны. Чтобы X_e = 0 и X_p = 9, вклад должен зависеть не от n и d, а от **типа стыка**. Это уже второе правило, а не одно.

### 4.3 Нейтрон и пионы (F3, F4): закономерности нет

Лестница сама по себе даёт n = p и π = μ (ошибки π± −24 %, π⁰ −22 %). Нужны добавки, которые лестница не даёт.

|---|---|---|---|---|---|
| F3 аддитивно, 6 мишеней | 8,96 % | 0,435 | 0,055 | 0,005 | 0,325 |
| F3 мультипликативно | 13,2 % | 0,110 | 0,085 | 0,005 | 0,640 |
| F4, три разности | 3,56 % | 0,100 | 0,025 | — | 0,070 |
| F4, только две разности пионов | 3,19 % | 0,995 | 0,985 | — | 0,990 |

(Нулевая модель «разности»: μ, τ, p остаются, разности n−p, π±−μ, π⁰−μ умножаются на случайный множитель от ½ до 2. Перестановка: массы перемешаны между формами. Перестановка отбрасывает только то, что лёгкие формы лёгкие, а тяжёлые тяжёлые; это не закономерность в смысле «простые числа».)

- [расчёт] Лучшее в F4: n − p = 2,50 (данные 2,531, −1,2 %); π± − μ = 64,0 (−3,6 %); π⁰ − μ = 58,5 (+2,0 %). Формулы при этом сборные: член (5/2)α^{−1/2}·[двойные точки] плюс член (1/4)·[присоед. × Σ_стыков k^{2d}].
- [вывод] Разности пионов **не выделяются среди случайных**: случайные разности подгоняются той же грамматикой лучше настоящих (медиана нулевой модели 1,0–1,3 % против 3,19 % на данных). Простые выражения π± − μ ≈ 1/(2α) (+3,2 %) и π⁰ − μ ≈ 5/√α = 58,5 (+2,0 %) — того же уровня.
- [вывод] F4 с P = 0,025–0,10 держится на одном числе: n − p ≈ 5/2·m_e (−1,2 %). Если учесть, что проверено пять семейств, это не значимо.
- [вывод из данных, не зависит от кодировки] Перпендикулярное присоединение восьмёрки через точку (n) добавляет 2,5 m_e, а перпендикулярный крест (μ) — 205,8 m_e. Обе точки двумерны. Значит, правило «2D → четвёртая степень» должно различать «крест в общем центре» и «через точку», иначе получится противоречие. Шкалы разные: ~1/α и ~α⁰.

## 7. Что это может значить в рамках W (кандидаты)

1. [кандидат] Опору в данных имеет только **лестница по плоскостям креста**: Σ_{j=1}^{d−1} j⁴ при C = 3/2 — то есть формула Барута. Задача W — вывести её, а не подобрать: почему коэффициент 3/2, почему вклад плоскости j⁴ (умножение по двум осям?) и почему у трёхмерного креста считаются две плоскости из трёх (j = 1, 2), а не три. Пока выбор «две плоскости, а не три (64)» сделан по данным. Это подгонка, и записывать её надо как открытый пункт.
2. [кандидат] Протону нужно своё правило: стык через общую двойную петлю, (число петель)². Это второй тип стыка. Он согласуется с данными на уровне случая (P ≈ 2–8 %). Чтобы он стал закономерностью, нужна независимая проверка: например, предсказать заранее массу формы с двумя общими петлями (четыре восьмёрки в цепочке, X = ?), до того как её искать.
3. [кандидат] Нужны **две шкалы**. Стыки в общем центре и через общую петлю дают ~1/α. Присоединение через точку к одномерному хозяину (n) даёт ~α⁰ (n − p ≈ m_e + 3/2·m_e, −1,2 %). Пионы (точка при 2D-кресте: 0,48/α; двойная точка: 0,42/α) лежат между шкалами, и простого правила для них в проверенной грамматике нет.
4. [открыто] Что нужно от теории, чтобы проверка стала возможной: одно определение счёта k для всех типов стыков, выведенное из обмена точек до сравнения с массами, и правило шкалы для присоединения через точку. Тогда массы n, π±, π⁰, D_s станут предсказаниями, а нынешний перебор в 2,45·10⁹ формул не понадобится.

## 8. Ограничения
- Кодировка (п. 1.4) — одна из возможных. Другие варианты для N, T и двойной точки меняют признаки n, π±, π⁰. На вывод п. 4.2 о μ, τ, p они не влияют: там присоединённых точек нет.
- Грамматика конечна. Отсутствие правила доказано только внутри неё.
- Нулевые модели (±10 %, ×/÷2, перестановка, «разности») дают разные P. Приведены все, ни одна не выбрана по результату.
- 200 повторов на модель: значения P для F3–F5 известны с точностью ±0,02–0,03. Для F1 повторов 20 000.
