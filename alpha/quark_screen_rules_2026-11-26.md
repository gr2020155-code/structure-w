# Правила счёта: какой размер у вызванных форм с частями кварков (26.11.2026)

Записано и отправлено на GitHub ДО счёта. Программа: `quark_screen.py`, запись — Р-95. Продолжение Р-92, В-334: из четырёх звеньев остались только части кварков.

## Что говорят положения

- Гасят формы среды, которые вызывает сам заряд (А-83, А-86, А-87); размер вызванной формы — D = 2ħ/(Mc), где M — масса этой формы.
- Гасят не только электронные формы: одни электроны дают рост OPAL около 93·10⁻⁵ против 440 ± 78 (данные). Значит, вклад тяжелее электрона есть.
- Части кварков свободно не существуют — только внутри целого (В-304 п. 4). Значит, вызванная форма, несущая часть кварка, — целая форма.
- Какая именно масса у вызванной формы с частью кварка, в положениях не записано. Отсюда развилка.

## Прочтения (закрытый список)

M — масса вызванной формы, которая задаёт D для части данного вида. N_c·Q² — как в В-304.

- **K1 — своя масса части внутри бариона** (Rb, В-313): u = d = m_p/3 = 312,8; s = 490,2; c = 1660,9; b = 4994,1 МэВ. Это прежний счёт Р-91.
- **K2 — масса самой лёгкой заряженной целой формы с этой частью** (вызванная форма — целая, своя масса у неё целиком): u, d — π± 139,57; s — K± 493,68; c — D± 1869,66; b — B± 5279,34 МэВ.
- **K3 — доля самой лёгкой целой формы из двух частей** (то же, что Rb, но для формы из двух частей, а не трёх): u = d = m_π±/2 = 69,79; s = m_K± − m_π±/2 = 423,89; c = m_D± − m_π±/2 = 1799,87; b = m_B± − m_π±/2 = 5209,55 МэВ.

Состав π, K, D, B (какие части в них) — из стандартной физики, как в Р-82. t везде — прямо (172 570 МэВ): t не образует целых форм. Всё остальное — как в Р-91 (S3, κ = 2/(3π), 1/q₀² = 66,29 ± 0,14, без W-бозона, длина спада f = 1 по В-333).

## Критерии (решено заранее)

- Ц1: |1/α_W(0) − 137,036| ≤ 0,28 (2σ).
- Ц2: рост OPAL в пределах 156·10⁻⁵ хотя бы в одном чтении импульса.
- Проходит ровно одно — [кандидат, выбрано данными]. Ни одного — части кварков в этих прочтениях недостачу не закрывают; так и записать.
