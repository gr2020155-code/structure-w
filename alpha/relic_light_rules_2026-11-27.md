# Правила счёта: реликт при законе «квадрат темпа — сумма долей» с долей света (27.11.2026)

Записано и отправлено на GitHub ДО счёта. Программа: `relic_light.py`, запись — Р-133.

Автор: «Предположим, что верно. Разберемся в таком случае с реликтом». Записывается как **А-105 (условно)**: квадрат относительного темпа роста плотности равен сумме долей (В-388).

## Закон

g² = g₀²·[Ω_r·u⁻⁴ + Ω_m·u⁻³ + Ω_B], u = k/k₀ = 1/(1+z), Ω_r + Ω_m + Ω_B = 1. Здесь:
- Ω_m·u⁻³ — самозамкнутые связи (масса, А-36), их доля ∝ 1/s;
- Ω_r·u⁻⁴ — свет: число световых изменений сохраняется, энергия каждого ∝ k (В-374, В-388 п. 5);
- Ω_B — постоянный темп.

## Откуда числа

1. **Ω_m и Ω_B** — из линейки (Р-132, Г2): Ω_m = A/(A+B). Подгонка линейки повторяется уже с членом света; при z < 2,4 он ничтожен.
2. **Ω_r = ρ_r/ρ_tot.**
   - ρ_γ = a·T₀⁴. Здесь T₀ = 2,72548 К (Д-79), a = 4σ/c — постоянная излучения; это измеренные постоянные.
   - ρ_tot = 3·g₀²/(8πG): **мост, модельный** — множитель между «долей» и квадратом темпа взят из официальной теории. В положениях величины этого множителя нет. G — измеренная постоянная.
   - **Ветвь ν0:** свет — только реликтовые фотоны, ρ_r = ρ_γ.
   - **Ветвь ν1:** плюс фон нейтрино по официальному расчёту, ρ_r = ρ_γ·(1 + 0,2271·3,046) — **мост, модельный**.
3. **g₀ = H₀ — меряю сам по Pantheon+.**
   - Калибраторы с расстояниями по цефеидам (IS_CALIBRATOR = 1, CEPH_DIST) дают M.
   - Сверхновые на 0,023 < z < 0,15 дают H₀, с формой d_L по Г2.
   - Полная ковариация, M и H₀ подбираются вместе.
   - Это обработанные данные — лестница расстояний.

## Счёт реликта

- θ = c_s·∫_{z*}^∞ dz/g / ∫₀^{z*} dz/g.
- Как прежде: c_s ∈ [c/√6, c/√3], 1 + z* ∈ [1000, 1400].
- **Проходит, если диапазон содержит 0,010411.** Новых подогнанных чисел нет.
- **Для сравнения, не засчитывается:**
  - θ при c_s = c/√(3(1 + R_b)), R_b = 3ρ_b/(4ρ_γ) при z*, с Ω_b·h² = 0,0224 — официальная доля барионов, мост. Это показывает, насколько сужается диапазон.
  - Какое Ω_r дало бы точное попадание при средних c_s и z*.

## Честно: что я знаю до счёта

- **H₀:** ожидаю около 73. Это значение SH0ES, оно получено из тех же калибраторов.
- **Прикидка в уме.** Ω_m·h² ≈ 0,297·0,53 = 0,158, Ω_γ·h² = 2,47·10⁻⁵. Отсюда:
  - доля света сравнивается с долей массы при 1 + z_eq ≈ 6400 (ν0) или 3800 (ν1);
  - член света уменьшает r_s примерно в 0,67 (ν0) или 0,60 (ν1) раза.
  - Ожидаю θ ≈ 0,0084–0,0142 (ν0) и ≈ 0,0075–0,0127 (ν1). Оба диапазона содержат 0,0104 — пройдёт.
- **Проверка слабая:** диапазон по c_s шириной в √2. Вариант с барионами (для сравнения) даст узкий диапазон — по нему и будет видно, есть ли точное совпадение.
