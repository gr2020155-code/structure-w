# Правила счёта: реликт «обратным» светом по восьмёрке (26.11.2026)

Записано и отправлено на GitHub ДО счёта. Программа: `reverse_light.py`, запись — Р-125. Продолжение В-379. Автор: «Посчитай варианты».

## Что из положений и чего нет

- **Красное смещение и путь в шагах** при данном z не зависят от того, прямой свет или обратный (В-374, В-379). Путь D = ∫(1+z) dT при k ∝ T^(2/3) (В-376), в единицах c·T₀.
- **Размер пятен.** θ = r_s/S, где S — насколько разошёлся пучок лучей за путь D. Направление само по себе S не меняет. S меняется, только если на пути что-то сводит или разводит лучи. Обратный путь отличается тем, что идёт через место «ноль», где сходятся все восьмёрки и круги (А-101, А-102).
- **Что место «ноль» делает с пучком, в положениях не сказано.** Поэтому считаю все три возможности.

## Варианты

### О1 — «ноль» ничего не делает с пучком

S = D, как у прямого света. Это повтор В-376.

### О2 — «ноль» собирает лучи (фокус)

Любое сведение лучей на пути делает S < D (сравнение Рауха: пучок при сведении расходится не быстрее, чем без него). Тогда θ больше, чем у прямого света. Проверка по сетке: собирающая линза силой P > 0 на расстоянии D_L < D, тогда S = D_L + (1 − P·D_L)(D − D_L). Берётся |S|, потому что после пересечения лучей картинка перевёрнута.

### О3 — поверхность рогового тора, свет по восьмёрке

- Сечение рогового тора через ось — ровно восьмёрка: два круга радиуса r, касающиеся в центре («ноль»).
- Свет идёт по меридиану, то есть по этой восьмёрке. Расхождение пучка задаётся кривизной поверхности: K = cos v / (r²(1 + cos v)).
  - v = 0 — внешний экватор;
  - v = π — место «ноль».
  - Расстояние между лучами J находится из J'' + K·J = 0, с J = 0 и J' = 1 у нас.
- Масштаб: r = R = c·T₀ — толщина трубки сейчас, как в Р-124. Этот выбор не подбирался.
- **Наше место v₀ на восьмёрке в положениях не задано.** Это одно подогнанное число: перебираю v₀ от 0 до π.
- Для каждого v₀ считаю два направления:
  - прямое — от «ноля», по внешней стороне;
  - обратное — к «нолю» и через него.
- Если путь проходит точно через «ноль», в поверхностной модели J → ∞. Тогда θ → 0: пятна стёрты. Это засчитывается как «не проходит».

## Критерий (решено заранее)

- **Реликт:** диапазон θ при c_s ∈ [c/√6, c/√3] и 1 + z_r ∈ [1000, 1400] должен содержать 0,010411.
- **Сверхновые** (свет прямой, по автору): Δχ² относительно мерки Р-90. Х-11 этим расчётом не снимается: плоский закон уже даёт +702 (Р-124). Поэтому условие для варианта — не хуже плоского, Δχ² ≤ +702. Порог ≤ 10 тоже сообщаю: он не будет выполнен, пока стоит Х-11.
- Вариант О3 проходит при каком-то v₀, если обратный свет даёт реликт в диапазоне, а прямой свет для сверхновых при том же v₀ не хуже плоского.
- Если пройдёт только прямой свет для реликта, это сообщается отдельно, а не как подтверждение мысли автора.

## Честно: что я знаю до счёта

- **О1:** не проходит, θ = 0,0112–0,0189 (Р-124, Г0).
- **О2:** не проходит ни при каком D_L, P — это следует из сравнения. Нужно обратное: S больше D в 1,08–1,82 раза.
- **О3:**
  - если обратный путь пересекает «ноль» (v₀ > π − D_r ≈ 0,23), то S бесконечно и пятна стёрты;
  - при малом v₀ реликт оказывается близко к «нолю», где кривизна сильно отрицательная. Там пучок сильно разводится, θ может стать слишком мал.
  - Где попадёт, в уме не знаю.
  - Для сверхновых прямой путь сначала идёт по внешней стороне (K > 0, сведение). Это делает их ярче, то есть хуже. Ожидаю, что условие «не хуже плоского» будет нарушено.
