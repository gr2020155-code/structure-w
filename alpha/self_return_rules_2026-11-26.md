## Общая модель (из положений и записей)

- **Первый порядок.** Связь заряда с собой за оборот — α. Это доля актов петли заряда, которые уходят в среду и возвращаются (В-229 п. 3, В-240). На радиан приходится α/2π (А-66).
- **Как далеко уходит толчок (М1).** Среда несёт за радиусом r долю R/r собственной энергии поля вне обхода (В-233, В-245 п. 3). Поэтому толчок доходит до расстояния r (от центра обхода) с плотностью вероятности p(r) = R/r², где r ≥ R.
- **Ветвь М2.** Возвращаются только толчки, ушедшие не дальше размера электрона D = 2R: там есть вызванные формы (А-87). Тогда p(r) = 2R/r² на [R, 2R].
- **Время возврата.** Толчок идёт со скоростью c туда и обратно от обхода: τ = 2(r − R)/(2πR) = (r/R − 1)/π, в долях обхода. Фаза вылета φ равномерна на [0, 1).

## Ветвь A — чередование петель (А-84, А-83)

Петля электрона меняется каждый обход (O↔A, затем O↔B, противоположной ориентации). Толчок, который вернулся на обходе с номером n = ⌊φ + τ⌋:
- при чётном n встречает ту же петлю и считается как +1;
- при нечётном n встречает петлю противоположной стороны:
  - A1 — гасится (0);
  - A2 — считается со знаком −1.

δ_A = P(n нечётно) для A1 и 2·P(n нечётно) для A2. Ветви: A1, A2 × М1, М2 — всего 4.

## Ветвь B — гашение на обратном пути (А-86, А-87)

Внутри области вызванных форм толчок заряда гасится. По росту α (В-286, В-289) доля, гасящаяся на e-кратном расстоянии, — κ·α, где κ = 2/(3π). Толчок проходит область между R и границей r_b:
- B1 — гасится только на обратном пути;
- B2 — на пути туда и обратно.

Граница области:
- **резкая:** r_b = D = 2R;
- **с краем:** r_b = D·e^E, E = −2,1037 (В-286).

Потеря у толчка, дошедшего до r: n_ног·κα·ln(min(r, r_b)/R), если r_b > R, иначе 0. Тогда δ_B = среднее по p(r). Ветви: B1, B2 × резкая, с краем × М1, М2 — всего 8.
