## Чтение (кандидат, найдено после данных — раскрываю)

Уровень 3 разворачивается трубкой вокруг круга 30 (В-375). В каждом месте три оси:

- **вдоль круга** — различима полностью с самого 30: круг уже есть (А-98);
- **две поперёк** — различимы на долю x = r/R, где r = c·T — толщина трубки (растёт на шаг за такт, А-103). При x = 1 трубка — роговой тор, то есть 3W (А-102, В-373).

**1. Путь света.** Шаги на единицу пути ∝ s^(1/3) (В-375, G2). Это среднее геометрическое долей трёх осей: (1·x·x)^(1/3) = x^(2/3). Отсюда k ∝ T^(2/3) — уже записанный закон (В-376). Это не новое, а проверка согласованности чтения.

**2. Излучение.** Энергия взрыва за такт делится поровну на три степени свободы (А-98: на уровне 3 их три). По каждой оси в свет уходит доля, равная различимой доле этой оси. Тогда:

L ∝ (1 + 2x)/3 — среднее арифметическое.

С x = x₀·T/T₀:

L/L₀ = (1 + 2x₀·T/T₀)/(1 + 2x₀) = 1 − a·(1 − T/T₀), где a = 2x₀/(1 + 2x₀).

Это ровно вид Ф3, найденный по данным (В-384).

**Что в чтении не из положений:** что энергия делится поровну на три степени свободы и что каждая ось пропускает в свет свою различимую долю. Это моё допущение, его нужно подтвердить автору.
