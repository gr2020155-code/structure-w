# Сложение спинов частей формы: правила, записанные до счёта (26.11.2026)

Задача: вывести из положений правило S3 (В-308) — веса +2/3, +2/3, −1/3 у частей протона, — без которого момент нуклонов опирается на правило кварковой модели, а не на W (В-256).

**Оговорка честности.** Какой вес нужен данным, известно заранее (В-308). Поэтому данные здесь не выбирают: прочтение засчитывается, только если каждый его шаг следует из положений; данные — контроль. Список прочтений закрыт до счёта.

## Положения

- А-08, В-25, В-27 [кандидат]: спин части-восьмёрки и формы целиком — ½ (правило 2:1).
- А-23, В-305: протон — петли (+), (−), (+) с долями u, d, u; нейтрон (В-310) — d, d, u, где обе d — петли «−».
- А-31: неразличимое не может иметь разный вес. А-39: доли — по квадратам. В-304: направление в 3D делится по квадратам на три оси, ни одна не выделена.
- Принцип автора «не лего»: форма — одно целое; её ось задаёт целое, а не части.
- Р-78, В-308: момент части w·Q·(k·m_p/M) μ_N (R2), w — проекция спина части на ось формы в единицах ½.

## Шаги рассуждения и развилки

1. **Величина спина одной части.** Проекция на ось формы — ½. Остальные две оси:
   - M1: вклада нет (спин — только вдоль оси): |s|² = (½)² = 1/4.
   - M2: по А-31 ни одна ось не выделена, по А-39 и В-304 доли — по квадратам на три оси; у каждой оси та же доля (½)²: |s|² = 3·(1/4) = 3/4.
2. **Пара одинаковых частей** (две петли одной ориентации: u, u в протоне; d, d в нейтроне) — по оси сонаправлены (одинаковая ориентация петли).
   - P1: поперечные составляющие частей независимы (положения не связывают их — связь была бы отдельным правилом): s₁·s₂ = ¼ + 0 + 0 → |S|² = 2·|s|² + ½.
   - P2: пара жёсткая, поперечные составляющие совпадают: s₁·s₂ = |s|² → |S|² = 4·|s|².
3. **Целое.** Форма — одно целое со спином ½ (А-08, «не лего»): |J|² — по тому же правилу, что у одной части (M1: 1/4, M2: 3/4), проекция J_z = ½.
4. **Что измеряется.** Ось формы задаёт целое; поперечные к J составляющие частей при обращении формы усредняются, остаётся проекция на J: w_i = 2·(s_i·J)/|J|²·J_z. Скалярные произведения — из треугольника J = S + s₃: S·J = (|J|² + |S|² − |s₃|²)/2, s₃·J = (|J|² + |s₃|² − |S|²)/2; каждой части пары — половина проекции пары.

Прочтения: M1 (поперечных нет, P не важно), M2·P1, M2·P2 — три.

## Что сообщается

Для каждого прочтения: веса w (u, u, d) и (d, d, u); μ_p и μ_n при R2 (данные 2,793 и −1,913); отношение. Отдельно — наблюдение, не доказательство: какое |J|² даёт прочтение для N сонаправленных частей (у трёх — Δ, спин 3/2), сравнить с N/2·(N/2 + 1) из стандартной физики.

## Ожидание до счёта

M2·P1 даёт веса 2/3, 2/3, −1/3 (μ_p = 3, μ_n = −2); M1 и M2·P2 — классическое «две вверх, одна вниз» (веса 1, 1, −1, μ_p = 5). Если так, правило S3 следует из шагов M2 (три оси поровну) и P1 (независимость поперечных частей) при спине ½ целого. Слабые места заранее: спин ½ — кандидат (В-27); шаг 4 (проекция на целое) — прочтение «не лего»; противоречие В-31 (обход несёт ħ, а не ħ/2) этим не снимается.
