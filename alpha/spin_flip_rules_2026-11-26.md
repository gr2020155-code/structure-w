# Правила счёта: что при перевороте не участвует в обходе — все ветви (26.11.2026)

Записано и отправлено на GitHub ДО счёта. Программа: `spin_flip.py`, запись — Р-104. Продолжение В-346 п. 5–6. Автор: «не знаю — посчитай».

## Что фиксировано

- Радиус обхода R = ħ/(mc) задаётся частотой mc²/ħ (А-04) и скоростью c (В-13, В-12). От того, какая доля инерции идёт по обходу, R не зависит. Поэтому μ = e·c·R/2 = μ_B при любой ветви: заряд проходит обход полностью.
- Пусть f — доля инерции, которая идёт по обходу. Тогда момент обхода L = f·ħ, при перевороте передаётся ΔL = 2f·ħ, а g′ = 1/f.

## Ветви

**(а) Часть инерции не идёт по обходу.** Инерция — отставание частицы от её глобальной восьмёрки (А-60, В-212). У отставания два участника: ядро на обходе (уровень 2) и глобальная восьмёрка (уровень 3, А-09). Ядро меньше обхода в 10⁷ раз (В-10), поэтому всё ядро идёт по обходу.
- а1 — вся инерция в ядре: f = 1.
- а2 — инерция поровну между ядром и одной глобальной восьмёркой (участники отставания равноправны, А-31); восьмёрка по обходу не идёт: f = 1/2.
- а3 — поровну между ядром и тремя глобальными восьмёрками (у электрона их «одна или три», А-73): f = 1/4.
- а4 — вся инерция в глобальной восьмёрке: f = 0.

**(б) Разворачивается не весь обход.**
- б1 — две восьмёрки электрона — две системы (В-42), каждая несёт половину момента обхода, разворачивается только заряженная: ΔL = ħ, то есть f = 1/2. Проверить, не спорит ли это с тем, что форма движется целиком (В-198).
- б2 — по правилу 2:1 момент ориентации равен ħ·j при наименьшем j = ½ (В-27): f = 1/2. Посылка «ħ·j» — вне положений (В-27 сам это отмечает).

## Критерии (решено заранее)

1. **Один фотон на переворот.** По А-04 переворот поглощает или испускает один квант ħω_s. Фотон несёт ħ (Д-07, Бет), целое не меняется (А-28), значит ΔL = ħ и f = 1/2 точно.
2. **Эйнштейн — де Хааз (Д-05).** Орбитальная часть даёт g′ = 1 и только понижает смесь, поэтому должно быть g′ = 1/f ≥ 1,919 − 2·0,002 = 1,915.
3. **Положения.** Ветвь не должна спорить с записанными выводами (В-198, В-10).

Ветвь проходит, если выполнены все три критерия. Если прошли две и больше, данные между ними не выбирают; тогда сравнить, какие посылки у каждой ветви — из положений или вне них.

## Честно: что я знаю до счёта

Ожидаю: проходят а2 и б2 (обе дают f = 1/2), б1 отпадает по В-198, а1, а3, а4 — по критериям 1–2. Данные а2 и б2 не различат. Довод в пользу а2 — её посылки из положений (А-60, А-09, В-212). Слабое место а2 — «поровну» по А-31: А-31 говорит о неразличимых актах, а ядро и глобальная восьмёрка — разные роли.
