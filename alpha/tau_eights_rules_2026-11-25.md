# Тау: три или четыре восьмёрки — правила записаны до счёта (25.11.2026)

Положение автора (25.11): для пространства три восьмёрки не отвергнуты, четыре (два креста) — предположение. Проверяются оба варианта формы тау.

Основа — кандидатная лестница В-184/В-191: прибавка массы = (3/2α)·X·m_e; мюон X = 1, тау (крест + восьмёрка) X = 1⁴ + 2⁴ = 17. Сама лестница — подгонка (формула Барута, 1979), поэтому проверка слабая: она показывает только, какие счёты вообще совместимы.

Счёт X для тау из четырёх восьмёрок — три прочтения «что считается единицей»:
- R1: единица — каждая добавленная восьмёрка, номер по порядку добавления j = 1, 2, 3: X = Σ j⁴.
- R2: единица — уровень; уровень с номером j даёт j⁴, сколько бы восьмёрок в нём ни было.
- R3: единица — восьмёрка, вес — номер её уровня в четвёртой степени; на третьем уровне две восьмёрки.

Тау из трёх восьмёрок при всех трёх прочтениях даёт X = 17 (как было).
