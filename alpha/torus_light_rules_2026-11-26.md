# Правила счёта: расхождение света при форме пространства — роговой тор (26.11.2026)

Записано и отправлено на GitHub ДО счёта. Программа: `torus_light.py`, запись — Р-124. Продолжение В-377 (Х-11), причина (б). Автор: «Свет на роговом торе».

## Что из положений и чего нет

- **Закон плотности** k ∝ T^(2/3) (В-376, трубка от круга 30), расстояние по пути D = ∫(1+z) dT (В-374).
- **Форма.** Пространство — трубка вокруг круга 30, к 3W это роговой тор (А-102, В-373). Толщина трубки растёт на шаг за такт, поэтому её естественный масштаб сейчас — r₀ = c·T₀, по местному счёту тактов (В-370).
- **Правила, по которому свет идёт по такой форме, в положениях нет.** Не сказано, по прямым внутри трубки или по её окружностям. Поэтому проверяю общее: если форма меняет площадь, по которой расходится свет, это действует как кривизна. Кривизна меняет сразу две наблюдаемые:
  - поток сверхновых: d_L = (1+z)·S(D);
  - угол пятен реликта: θ = r_s/S(D_r).

Здесь S — «поперечное расстояние»:
- Г0, плоско: S = D;
- Г+, положительная кривизна (замкнуто): S = ρ·sin(D/ρ);
- Г−, отрицательная кривизна: S = ρ·sinh(D/ρ).

У поверхности рогового тора внутренняя сторона (около центра) имеет отрицательную кривизну, внешняя — положительную.

## Ветви

- **Без подгонки.** ρ = r₀ = c·T₀ и ρ = 2·c·T₀ (радиус и диаметр трубки сейчас), для Г+ и Г−; плюс Г0.
- **С одним подогнанным числом (наблюдение):** ρ свободно, подбирается по сверхновым. Затем по этому ρ предсказывается θ реликта — это проверка на другом наборе данных.

## Критерий (решено заранее)

- **Сверхновые** (Pantheon+, мерка Р-90 χ² = 1403,3): Δχ² ≤ 11 без подгонки; ≤ 10 с одним подогнанным числом.
- **Реликт:** θ при c_s ∈ [c/√6, c/√3] и 1 + z_r ∈ [1000, 1400] должен содержать 0,010411.
- Ветвь проходит, только если проходит обе проверки.

## Честно: что я знаю до счёта

- **Г+** делает сверхновые ярче, а пятна крупнее — хуже по обоим: не пройдёт.
- **Г−, ρ = c·T₀.** На z = 1 D = 0,88·cT₀, sinh-множитель 1,14 → +0,28 зв. вел. (нужно около +0,4). Для реликта D_r = 2,91·cT₀, множитель 3,2 → θ ≈ 0,0035–0,006 — слишком мелко.
- **Г−, ρ = 2·c·T₀.** Реликт θ ≈ 0,008–0,014 — попадает; сверхновые лишь +0,07 зв. вел. — мало.
- **Ожидание:** сверхновым нужна ρ ≈ 0,7–0,8·cT₀, реликту — ρ ≈ 2·cT₀. Одна постоянная кривизна обоих не даст. Если так, то влияние формы, если оно есть, не одинаково на всех расстояниях: оно зависит от того, как путь света проходит около центра тора. Это прикидка в уме.
