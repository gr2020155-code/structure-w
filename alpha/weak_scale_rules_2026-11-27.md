## Что проверяю

Слабая шкала: λ_F = 6,74·10⁻¹⁹ м, масса M_F = 1/√G_F = 292,80 ГэВ, число тактов N_F = m_P/M_F = 4,17·10¹⁶ (В-301). Из нынешних положений она не выводится (А-14, В-302, В-318).

Две ветки автора:
- **(б)** N_e и N_F задаются полным числом точек N_tot (А-91) через единственную траекторию.
- **(в)** слабая шкала — предел самой тяжёлой формы (верхний кварк).

## Данные (Д-86)

- m_P = 1,220890·10¹⁹ ГэВ.

## Проверка Б (ветка б)

**Правило.** N_X = N_tot^(p_X), без множителей. Показатели берутся из размерностей и числа встреч: p = i/j, 1 ≤ i ≤ j ≤ 4 (j = 1, 2, 3 — мерность, 4 — четыре встречи слабого распада, В-301 п. 3).

**N_tot неизвестно**, поэтому проверка идёт через отношение. Из электрона: N_tot = N_e^(1/p_e). Отсюда предсказание N_F = N_e^(p_F/p_e).

**Критерий:**
- Ветка проходит, если хоть одно отношение p_F/p_e < 1 даёт N_F с точностью |ln(N_F,модель/N_F)| ≤ 0,02 (2 %, как точность лестницы масс, В-184).
- Засчитывается только M_F. Шкалы v = (√2·G_F)^(−1/2), M_W, M_Z — для сравнения, не засчитываются: выбор шкалы после счёта был бы подгонкой.

**Контроль случайности.** Доля случайных мишеней (ln N_F равномерно на [0,5; 1]·ln N_e), которые попадают в какое-нибудь отношение с той же точностью. Если доля большая, совпадение ничего не значит.

## Проверка В (ветка в)

**Правило.** У самой тяжёлой формы слабая доля β_w = G_F·m² (определение В-176) равна одной из долей, известных в положениях. Список задан до счёта:

| Доля | Откуда в положениях |
| --- | --- |
| 1 | насыщение: переход каждый цикл, как N = 1 и q = 1 (В-246) |
| 2/3 | заряд верхнего кварка: две оси из трёх (В-304) |
| 1/2 | два равноправных конца (А-97, В-348) |
| 4/9 | квадрат заряда Q² (вес гашения N_c·Q², В-304) |
| 1/3 | одна ось из трёх (В-304) |

**Окно данных.** Масса кварка зависит от определения (в теории КХД разница ~6 %), поэтому окно берётся от нижнего края MS-bar (161,0 ГэВ) до верхнего края прямых измерений (172,87 ГэВ).

**Критерий:**
- Проходит, если в окно попадает ровно одна доля.
- Если ни одной — ветка отвергнута.
- Если несколько — не решено.

**Контроль случайности.** Доля случайных значений (логарифмически равномерных на [0,25; 1]), которые попадают хоть в одну долю списка при той же ширине окна.

**Следствие при прохождении:** M_F = m_t/√s. Задача тогда переходит к отношению m_t/m_e, которого в W нет. λ_F от этого не выводится, а только сводится к массе верхнего кварка.

## Честно: что я знаю до счёта

**Б.** Прикинул в уме: ln N_F/ln N_e ≈ 0,743. Ближайшая простая дробь 3/4 даёт N_F ≈ 6·10¹⁶ против 4,17·10¹⁶ (+46 %). Ожидаю: не проходит. Контроль случайности, по прикидке, — несколько процентов.

**В.** Заметил заранее: G_F·m_t² ≈ 0,35 (прямая масса), близко к 1/3. При MS-bar — ≈ 0,31. Ожидаю: в окно попадёт 1/3, и только она.

Но окно широкое: случайное попадание, по прикидке, около 50 %. Поэтому прохождение В — не проверка, а только «не отвергнуто». Опровергнуть ветку оно может, подтвердить — нет. По правилу подгонки выбор 1/3 замечен до правил, раскрываю. Выводом он станет, только если «одна ось из трёх» для слабой доли самой тяжёлой формы будет выведена из положений.
