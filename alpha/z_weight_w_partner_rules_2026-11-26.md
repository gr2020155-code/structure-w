# Правила счёта: вес распадов Z и партнёр W со спином 0 (26.11.2026)

Записано и отправлено на GitHub ДО счёта. Программа: `z_weight_w_partner.py`, запись — Р-107. Продолжение В-349 п. 3–4. Автор: «оба варианта».

## Часть 1. Вес распадов Z

**Данные:**
- доли Z (Д-70);
- R_b = 0,21629 ± 0,00066, R_c = 0,1721 ± 0,0030 — доли b b̄ и c c̄ среди адронов (PDG по arXiv:1804.10236 и 1401.2447, сверено 26.11);
- M_W = 80,3625 (Д-69), M_Z = 91,1876 ГэВ.

**Прочтение.** Z нейтрален и связан с частью двумя путями:
- (i) как W — по месту части в делении: верхний член пары (ν, u — петля «+» или без заряда) — +½, нижний (e, d — петля «−») — −½ (В-305);
- (ii) как фотон — по заряду Q = ±k/3.

Вес варианта w = T² + (T − 2Q·s²)², где T = ±½, а s² — доля смешивания двух путей. **Сам вид веса — мост, модельный**: он из стандартной электрослабой теории, в W не выведен. У кварков, как раньше, множитель (1 + ε), ε = 0,251/ln(M_Z/312,8 МэВ).

**Ветви s²:**
- ZA — из данных о массах: s² = 1 − (M_W/M_Z)². Связь масс с углом — тоже мост.
- ZB — s² подогнан по доле невидимых. Проверка — остальные четыре числа.
- ZC — числа W: 1/4, 2/9, 1/3. **Раскрываю:** 2/9 = 0,2222 близко к 1 − (M_W/M_Z)² = 0,2233, я это заметил до счёта. Доводом это не служит: правила для s² в W нет.

**Критерий.** Невидимые, ℓ, адроны, R_b, R_c — каждое в пределах 2σ. Ошибка — данные и ошибка ε, сложенные квадратично.

## Часть 2. Партнёр W со спином 0

**Что следует из W.** По В-348 две половинки дают 0 и 1. Значит, рядом с W (спин 1) должна быть заряженная форма тех же частей со спином 0, а рядом с Z — нейтральная.

**Данные о парах «спин 1 / спин 0» из тех же частей** (массы PDG, по памяти, сверить): ρ 775,3 / π 139,6; K* 891,7 / K 493,7; D* 2010,3 / D 1869,7; B* 5324,7 / B 5279,3; J/ψ 3096,9 / η_c 2983,9; Υ 9460,3 / η_b 9398,7 МэВ.

**Счёт:**
1. Проверить по данным, всегда ли спин 0 легче.
2. Подогнать Δ = A/M^p (Δ = M₁ − M₀) по четырём тяжёлым парам (D, B, J/ψ, Υ). Продолжить до M_W и M_Z — это закономерность данных, не вывод W. Разброс оценить, считая отдельно p = 1 и p свободным.
3. Сравнить с поиском LEP: заряженные формы со спином 0, распадающиеся на τν и cs̄, исключены ниже 80 ГэВ (arXiv:1301.6065, тип II; 72,5 ГэВ в типе I).

**Критерий.** Если ожидаемая масса партнёра ниже предела LEP больше чем на разброс, прочтение «две половинки» в этом виде опровергнуто. Иначе — не опровергнуто, и записать, где партнёра искать.

## Честно: что я знаю до счёта

- Часть 1: стандартная теория с s² ≈ 0,231 описывает Z хорошо. Ожидаю: ZA (0,223) немного не проходит по лептонам; ZB проходит почти всё, возможно, кроме R_b; ZC — только как чувствительность.
- Часть 2: прикинул Δ·M ≈ 0,25–0,6 ГэВ². Для W это Δ ≈ 3–8 МэВ, то есть партнёр прячется внутри пика W (ширина 2,1 ГэВ) — выше предела LEP. Ожидаю: «не опровергнуто, по массе не отделить».
