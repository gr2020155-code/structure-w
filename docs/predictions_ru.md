# Структура W: что можно проверить

Nov 26, 2026 · @Garik Asatryan

## Отличия от стандартной физики

Отличий в измеримой области два. (1) В структуре W-бозон не гасит заряд: он пара уже учтённых частей (В-358), поэтому выше \~160 ГэВ α растёт быстрее, чем по стандартному счёту (В-294). (2) У пар заряженных лептонов тот же избыток рождения, что у частей кварков: ε = α = 0,73 % для e⁺e⁻ → μ⁺μ⁻, по КЭД — 0,17 % (В-355, В-356). Сейчас оба скрыты в неточности данных.

| Что измерять | Структура W | Стандартная физика | Данные сейчас |
| --- | --- | --- | --- |
| Рождение пар лептонов большой массы на LHC | больше на 1,6 % (200 ГэВ), 3,2 % (500 ГэВ), 4,4 % (1 ТэВ), 5,7 % (2 ТэВ) | базовый расчёт | CMS 13 ТэВ: ошибки 12–160 % — не решают |
| Отношение нейтрального тока (γ, Z) к заряженному (W) при одной массе пары | растёт с массой на несколько процентов быстрее | базовый расчёт | в таком виде не опубликовано |
| e⁺e⁻ → μ⁺μ⁻ относительно точечного счёта (нормировка на Баба или γγ) | +0,73 % | +0,17 % | CMD-3 1,0017 ± 0,0063, BaBar 1,0040 ± 0,0111 — не решают; нужно 0,28 % (В-356, В-357) |

Как проверить: нужна точность 1–2 % при массах около 1 ТэВ. В отношении нейтрального тока к заряженному неточность распределения кварков в протоне почти сокращается, поэтому это чистая проверка (В-299 п. 9). Риск для структуры: стандартная модель с вкладом W уже описывает 17 точных электрослабых величин (p = 0,68), и структура обязана получить те же числа без этого вклада.

Структура воспроизводит измеренные числа из своих положений. Это объяснения, а не предсказания: числа были известны заранее, поэтому все они в статусе «кандидат».

| Рост α между 1,81 и 6,07 ГэВ² | (306–400)·10⁻⁵ | (440 ± 78)·10⁻⁵ (OPAL) | В-330 |
| Форма роста α у размера электрона (числа 5/6 и γ) | тождественно | потенциал Юлинга | В-286 |

## Пока не проверить

Эти утверждения структуры лежат за пределами нынешних измерений или совпадают с стандартной физикой там, где мерить уже можно.

| Утверждение | Число | Почему не проверить | Запись |
| --- | --- | --- | --- |
| Шаг пространства | a = 2π·l\_P = 1,016·10⁻³⁴ м | измерения достают \~10⁻¹⁹ м | В-271 |
| Граница шага без условий | a ≤ 74·l\_P | там же | В-252 |
| Доля источника заряда на самом шаге | q₀ = 0,12289, 1/α на шаге ≈ 66,2 | там же | В-359 |
| Новые заряженные частицы тяжелее \~8 ТэВ | для роста α не нужны | отсутствие доказать нельзя, можно только не найти | В-292, В-307 |
| Тяготение на малых расстояниях | G постоянна, α/G меняется | тяготение измерено не ближе \~5·10⁻⁵ м; со стандартной физикой совпадает | В-272 |
| Предельная масса частицы | ровно планковская | недостижимые энергии | В-246 |

Открыто и даёт новые числа, если будет выведено: слабая длина λ\_F (а с ней масса W и времена жизни μ, τ, нейтрона) и абсолютные массы — сейчас калибровка (А-14, В-301, В-302).

## Слабые места и источники

Итог по α держится на трёх непроверенных звеньях; каждое может сдвинуть его на десятые доли.

- **W-бозон не гасит заряд** (В-294, В-299): ни через массу W, ни по данным LHC пока не проверено.
- **«Остаток пары — это доля q₀, а не α»** (В-295): правило чередования записано 18.11 до счёта, но прочтение сделано 25.11, когда цель была известна.
- **Перевод «энергия → расстояние» для адронной части** (Р-72): поправка γ взята для логарифмического хода, для адронов это приближение.

Массы частиц во всех счётах — измеренные, не выведенные (А-14). Правила всех счётов записаны до запуска (папка `alpha/`, файлы `*_rules_2026-11-25.md`); номера В-, Р-, Д- — записи матрицы `matrix.json`.
